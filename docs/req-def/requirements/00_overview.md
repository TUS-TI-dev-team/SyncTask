# 00. システム概要・業務要件

## 1. システム概要

### 1.1 背景
- チーム開発の学習のため。

### 1.2 目的
- 個人向けのクロスプラットフォーム対応タスク管理Webアプリを作成し、端末間でタスク管理を行えるようにすること。
- チーム開発の手法について学ぶこと。

### 1.3 プロジェクト概要
- 個人のユーザーが利用するタスク管理用Webアプリケーション（SyncTask）を構築・開発する。

---

## 2. 業務要件（システム要件）

### 2.1 利用目的
- 個人ユーザーによる日々のタスク管理。

### 2.2 利用者の範囲
- **対象**: 大学生
- **想定規模**: 数人規模

### 2.3 期待する成果・完了条件
- ユーザー自身がタスクを作成・管理できること。
- 自分のタスクの進捗状況を的確に把握・記録できること。
- これらを通じて、効率的なタスク管理を可能にすること。
