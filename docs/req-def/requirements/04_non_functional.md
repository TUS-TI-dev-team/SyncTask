# 04. 非機能要件

本ドキュメントでは、SyncTaskにおける性能、可用性、対応プラットフォーム・ブラウザ環境、および運用・保守性に関する要件を定義します。

---

## 1. 性能要件 (Performance)

| 項目 | 目標値・要件仕様 |
| :--- | :--- |
| **応答速度（ターンアラウンドタイム）** | 全てのページ・画面操作において **2秒以下** とする。 |

---

## 2. 可用性要件 (Availability)

| 項目 | 目標値・要件仕様 |
| :--- | :--- |
| **稼働率** | **90% 以上** |

---

## 3. 対応プラットフォーム・動作環境

### 3.1 PC 環境
| 項目 | 対応環境 |
| :--- | :--- |
| **OS** | ・Windows<br>・Linux |
| **対象ブラウザ** | ・Google Chrome<br>・Microsoft Edge<br>・Mozilla Firefox |

### 3.2 スマートフォン環境
| 項目 | 対応環境 |
| :--- | :--- |
| **OS** | ・**Android**<br>※ **iOS は非対応・動作保証外** とする。 |
| **対象ブラウザ** | ・Google Chrome<br>・Mozilla Firefox |

---

## 4. 運用・保守性要件 (Operation & Maintenance)

### 4.1 サーバー異常通知
- サーバー異常時における管理者へのメール通知（管理者用メーリングリストへの送信等）は **送信しない**。
- *（将来的な検討メモ）*:
  - 送信を検討するトリガー: プログラムエラー発生時、ハードウェアメトリクス（CPU使用率、メモリ使用量、データベース容量の閾値超過）。

### 4.2 バックアップ方針
- 現フェーズにおいて、定期バックアップは **一旦取得しない** 方針とする。
