# Task 02: ホーム画面の移植 (Home Page)

## 1. 担当概要

本タスクは、ログイン後のメインダッシュボードとなるホーム画面（`app/home`）およびその表示ビュー（`components/home/home-view.tsx`）を `SyncTask-Design-Idea` から `SyncTask/frontend` に移植する作業です。

---

## 2. 移行対象ファイル一覧

| 移行元 (Design-Idea) | 移行先 (SyncTask/frontend) | 概要 |
| --- | --- | --- |
| `components/home/home-view.tsx` | `components/home/home-view.tsx` | ホーム画面メインビュー（3つのタスクビュー切替、タスクリスト、上下ページネーション） |
| `app/home/page.tsx` | `app/home/page.tsx` | ホーム画面ページエントリーポイント |

※ タスクアイテム表示コンポーネント `components/tasks/task-card.tsx` を参照します。

---

## 3. 仕様書・設計との整合ポイント (`screen_design.md`)

- **3つのタスクビュー切り替え**:
  1. 「高優先度タスク一覧表示」（デフォルトビュー）
  2. 「締切間近タスク表示」
  3. 「ピン止めタスク表示」
- **完了タスク表示/非表示切り替えトグル**:
  - 高優先度・ピン止めタスク表示時: トグルで完了済みタスクの表示/非表示を切り替え可能。
  - 締切間近タスク表示時: 完了タスクは常に除外されるため、トグルは非活性（Disabled）または非表示制御とする。
- **ページネーション操作UI**:
  - タスクリストの **上下両方** に配置されていること。
  - 全ページ数 $N > 10$ の場合、現在のページ $n$ に応じた省略表示（`[1, 2, ..., n-1, n, n+1, ..., N]` 等）になっていること。
- **タスク作成トリガー**:
  - 「タスク作成」ボタン押下時に、タスク作成ダイアログが開くこと。
- **レイアウト適用**:
  - `components/layouts/app-shell.tsx` でラップされていること。

---

## 4. 作業手順

1. `components/home/home-view.tsx` を作成・配置する。
2. `app/home/page.tsx` を作成する。
3. `useStore` からモックタスク一覧を取得し、タブ切り替えおよび完了タスク表示トグルに応じたフィルタリング処理が正しく動作することを確認する。
4. 上下ページネーションが正しく動作することを確認する。
