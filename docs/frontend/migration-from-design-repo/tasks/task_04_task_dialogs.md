# Task 04: タスク操作ダイアログ群の移植 (Task Dialogs)

## 1. 担当概要

本タスクは、タスクの作成・編集・削除、およびカレンダー日付詳細モーダルを含むダイアログコンポーネント群を `SyncTask-Design-Idea` から `SyncTask/frontend` に移植する作業です。

---

## 2. 移行対象ファイル一覧

| 移行元 (Design-Idea) | 移行先 (SyncTask/frontend) | 概要 |
| --- | --- | --- |
| `components/tasks/task-form-dialog.tsx` | `components/tasks/task-form-dialog.tsx` | タスク作成 / 編集モーダル（単体作成・毎週繰り返し一括作成・入力バリデーション） |
| `components/tasks/delete-task-dialog.tsx` | `components/tasks/delete-task-dialog.tsx` | タスク削除確認ダイアログ |
| `components/tasks/date-detail-dialog.tsx` | `components/tasks/date-detail-dialog.tsx` | カレンダー日付詳細モーダル（当日タスク一覧・直接操作・該当日新規作成） |

---

## 3. 仕様書・設計との整合ポイント (`screen_design.md`)

- **タスク作成ポップアップ**:
  - タスク名（必須）、優先度（高/中/低）、締切り日時、コメント入力欄。
  - 「繰り返し作成」切り替えトグル / チェックボックス。
  - 繰り返し作成有効時: 開始日・終了日（カレンダーピッカー）、締め切り時刻、曜日選択チェックボックス（日〜土）を表示し、一括生成するロジック。
- **タスク編集ポップアップ**:
  - タスク名、ステータス（未着手/進行中/完了）、優先度、締切り日時、コメントの編集・更新。
- **タスク削除確認ダイアログ**:
  - 誤操作防止のための確認ダイアログ表示および削除実行。
- **日付詳細ポップアップ (`date-detail-dialog.tsx`)**:
  - 該当日付の表示。
  - 該当日締切タスクの一覧表示（タイトル、締切時刻、ステータスバッジ、優先度、コメント）。
  - ポップアップ内でのステータス直接変更、ピン止め操作。
  - 「新規タスク作成」ボタン（該当日付を締切日として事前入力した状態で作成モーダルを開く連携）。

---

## 4. 作業手順

1. `components/tasks/delete-task-dialog.tsx` を作成・配置する。
2. `components/tasks/task-form-dialog.tsx` を作成・配置する。
3. `components/tasks/date-detail-dialog.tsx` を作成・配置する。
4. ホーム画面やタスク一覧画面、カレンダー画面から各ダイアログが正しく呼び出され、モックStoreのデータが更新されることを確認する。
