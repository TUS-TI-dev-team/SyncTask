# タスク作成ポップアップにおける繰り返し自動作成フォームの動的表示切替および生成件数表示仕様の未定義

- **Status**: Open
- **Severity**: Medium
- **Created At**: 2026-08-18 21:05:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`docs/design/screen_design.md` の「タスク作成ポップアップ」において、「繰り返し作成」トグルのON/OFFに応じた単発タスク入力欄（締切日時）と繰り返し作成入力欄（期間・曜日・締切時刻）の動的表示切替仕様、および100件上限に対する生成予定件数の事前表示（プレビュー/カウンター）仕様が未定義です。

## 2. 詳細な指摘内容
- 要件定義書 `docs/req-def/requirements.md` L85-95 では、タスク作成において通常の単発作成（単一の締切日時指定）と、期間（開始日・終了日: YYYY/MM/DD）および曜日（日〜土）を指定した即時一括生成（最大100件/52週以内）が規定されています。
- `docs/design/screen_design.md` L34 では構成要素に以下が並列に記載されています：
  ```markdown
  タスク名入力欄<br>優先度選択プルダウン<br>締切り日時入力欄<br>コメント入力欄<br>「繰り返し作成」切り替えトグル/チェックボックス<br>期間指定（開始日・終了日）入力欄（カレンダーピッカー付き）<br>締め切り時刻(任意指定)<br>曜日選択チェックボックス（日〜土）<br>「決定」ボタン<br>「キャンセル」ボタン
  ```
- 主な問題点：
  1. **フォーム入力欄の排他・動的表示制御の欠落**: 「繰り返し作成」がOFF（デフォルト）の場合、期間指定・曜日選択・締切時刻入力欄は非表示（または非活性）とすべきであり、ONにした場合は単発用の「締切日時入力欄」を隠して「期間指定」「曜日選択」「締切時刻」を表示する動的フォーム制御が必要ですが、その挙動が明記されていません。
  2. **生成予定件数プレビュー（UX）の欠落**: 期間と曜日を選択した際に、要件上の制限（最大100件以内・1件以上）に適合しているかユーザーが送信前に視認できるよう、「○件のタスクが作成されます（上限100件）」のようなリアルタイム計算・生成件数プレビュー表示UIが定義されていません。

## 3. 推奨される修正案
`docs/design/screen_design.md` の「タスク作成（繰り返し自動作成）」補足（L42-44付近）に以下を追記してください：

- **繰り返し作成トグル連動フォーム表示仕様**:
  - `「繰り返し作成」OFF時（初期表示）`: 単発用の「締切り日時入力欄（日付・時刻）」を表示し、期間指定・曜日選択・繰り返し用締切時刻入力欄は非表示とする。
  - `「繰り返し作成」ON時`: 単発用の「締切り日時入力欄」を非表示とし、「期間指定（開始日・終了日）」「曜日選択チェックボックス（日〜土）」「締め切り時刻（任意、デフォルト23:59）」およびリアルタイム計算による「生成予定件数表示（例: 『計 12 件のタスクを生成します』）」を表示する。
  - 生成件数が0件または100件を超える場合は、決定ボタンを非活性化するか送信前に警告メッセージをリアルタイム表示する。
