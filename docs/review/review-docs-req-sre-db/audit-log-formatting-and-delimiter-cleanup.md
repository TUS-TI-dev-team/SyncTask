# ログ項目定義における区切り文字スペースの欠落・表記ゆれ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-18 19:55:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
「非機能要件 > ログ管理 > メール認証ログ」の処理イベント種別一覧において、区切り文字スラッシュの前後のスペースが欠落している箇所があります。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L253 に以下の記述があります：

```markdown
	- メール認証ログ
		- 日時、ユーザーID (UID、未登録・未ログイン時は null)、対象メールアドレス、認証種別（新規登録 / パスワードリセット / メールアドレス変更）、アクセス元IPアドレス、処理イベント種別（OTP発行 / 検証成功 / 検証失敗 / 手動再送依頼 / 5回失敗時自動処理/ 有効期限切れによる失効）、成否、ダミー処理区分（実処理 / ダミー表示）
```

上記のうち、`5回失敗時自動処理/ 有効期限切れによる失効` において、他の項目（`OTP発行 / 検証成功 / ...`）と異なりスラッシュ前後の半角スペースが抜けています。

## 3. 推奨される修正案
以下のようにスラッシュの前後に半角スペースを付与して表記を統一してください：

```markdown
	- メール認証ログ
		- 日時、ユーザーID (UID、未登録・未ログイン時は null)、対象メールアドレス、認証種別（新規登録 / パスワードリセット / メールアドレス変更）、アクセス元IPアドレス、処理イベント種別（OTP発行 / 検証成功 / 検証失敗 / 手動再送依頼 / 5回失敗時自動処理 / 有効期限切れによる失効）、成否、ダミー処理区分（実処理 / ダミー表示）
```
