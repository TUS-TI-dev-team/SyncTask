# カレンダー表示における締切日時未設定タスクの取り扱いおよび案内仕様の明確化

- **Status**: Open
- **Severity**: Minor
- **Created At**: 2026-08-18 20:15:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
カレンダー表示機能において「締切日時が設定されているタスク」を日付セルに配置する旨は記載されていますが、ユーザーが「締切日時未設定（NULL）のタスク」を作成した場合の扱い（カレンダー上には表示されないこと、およびリスト表示への切り替え等の案内方針）についての要件定義が曖昧です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L141 に以下の記述があります：

```markdown
		- カレンダー表示
			- 締切日時が設定されている全ステータス（「未着手」「進行中」「完了」）のタスクについて、日本標準時（JST）における日付（YYYY-MM-DD）のセル上に配置して表示する
```

### 問題点：
- 本システムではタスクの締切日時は任意（未指定可）です。
- カレンダー表示のみを利用しているユーザーにとって、締切日時未設定のタスクがカレンダー上に存在しないため、タスクが消失したと誤解するおそれがあります。
- 「締切日時未設定のタスクはカレンダー上には表示されないため、タスク一覧（リスト表示）で確認・管理する」仕様である旨を要件定義書および画面設計書に明確化しておくことが望まれます。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の L141 付近に以下の補足を追記してください：

```markdown
		- カレンダー表示
			- 締切日時が設定されている全ステータス（「未着手」「進行中」「完了」）のタスクについて、日本標準時（JST）における日付（YYYY-MM-DD）のセル上に配置して表示する（締切日時が未設定［NULL］のタスクは日付セル上には配置・表示されないため、タスク一覧画面のリスト表示にて確認・操作を行う仕様とする）
```
