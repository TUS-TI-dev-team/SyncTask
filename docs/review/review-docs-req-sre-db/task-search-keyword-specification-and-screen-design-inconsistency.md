# タスク検索仕様（キーワード検索と個別項目）の記述構造および画面設計との不整合

- **Status**: Open
- **Severity**: Medium
- **Created At**: 2026-08-18 20:15:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書の「タスク検索（and検索）」において、「キーワード検索（タスク名・コメント）」という統合検索の記述と、その下層にある個別項目「タスク名」「コメント」の記述が並列・重複して記載されており、画面設計（`screen_design.md`）の「検索用入力欄（キーワード）」との対応関係および検索論理（OR / AND）が曖昧になっています。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L127-138 に以下の記述があります：

```markdown
			- タスク検索（and検索）
				- キーワード検索（タスク名・コメント）は、入力された検索文字列の前後の空白文字を自動的に除去（トリム）し、英大文字・小文字、日本語全角・半角、ひらがな・カタカナを区別しない部分一致検索（Case-Insensitive）を行う（未入力またはトリム後空文字の場合はキーワードによる絞り込みを行わない）
				- タスク名
					- 含むものを検索（未入力時は絞り込みを行わない）
				- 優先度
					- 完全一致（高、中、低。未指定・すべて選択時は全優先度を対象とする）
				- 締切日
					- 指定日当日までの締め切り（〜指定日 23:59:59 JST）に該当する締切日時を持つタスクを検索。未設定（NULL）のタスクは除外する。未指定の場合は締切日による絞り込みを行わない
				- タスクステータス
					- 完全一致（未着手、進行中、完了。未指定時は一覧表示の「完了タスクを含める / 除外する」フィルタ設定に従う）
				- コメント
					- 含むものを検索（未入力時は絞り込みを行わない）
```

一方、画面設計書 `docs/design/screen_design.md` の L24 では、タスク一覧画面の検索UI構成要素として以下が定義されています：
- `検索用入力欄（キーワード）`
- `優先度絞り込みプルダウン`
- `締切日絞り込み入力欄`
- `ステータス絞り込みプルダウン`

### 問題点：
1. 画面設計上はキーワード入力欄が1つのみ提供されているのに対し、要件定義書側では「キーワード検索（タスク名・コメント）」に加えて、個別の「タスク名」「コメント」という項目が独立した箇条書きとして記載されており、入力欄が複数存在するのか1つなのかが誤解を招く構造になっています。
2. 統合キーワード検索の場合、入力されたキーワードは「タスク名に含まれる OR コメントに含まれる」タスクを対象とし、それと「優先度」「締切日」「ステータス」の各条件が AND 結合される仕様であることが一般的ですが、要件定義書の階層構造ではその論理関係が不明瞭です。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の L127-138 を整理し、画面UI（単一キーワード入力欄）と一致させ、検索論理条件を明確化してください：

```markdown
			- タスク検索（複合条件による絞り込み: 各条件間は AND 結合）
				- キーワード検索（タスク名 または コメントの部分一致）:
					- 入力された検索キーワードの前後の空白文字を自動的に除去（トリム）し、英大文字・小文字、日本語全角・半角、ひらがな・カタカナを区別しない（Case-Insensitive）で「タスク名」または「コメント」のいずれかに部分一致（OR条件）するタスクを検索する（未入力またはトリム後空文字の場合はキーワードによる絞り込みを行わない）
				- 優先度絞り込み:
					- 完全一致（高、中、低。未指定・すべて選択時は全優先度を対象とする）
				- 締切日絞り込み:
					- 指定日当日までの締め切り（〜指定日 23:59:59 JST）に該当する締切日時を持つタスクを検索。未設定（NULL）のタスクは除外する。未指定の場合は締切日による絞り込みを行わない
				- タスクステータス絞り込み:
					- 完全一致（未着手、進行中、完了。未指定時は一覧表示の「完了タスクを含める / 除外する」フィルタ設定に従う）
```
