# タスク編集ポップアップにおけるピン止め・締切解除・削除UIの構成要素欠落

- **Status**: Open
- **Severity**: Medium
- **Created At**: 2026-08-18 21:05:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`docs/design/screen_design.md` の「タスク編集ポップアップ」において、要件定義書で規定されている「ピン止め状態の変更」「締切日時の解除」「タスクの削除」を実行するためのUI構成要素（ピン止めトグル/チェックボックス、締切日クリアボタン、タスク削除ボタン）が構成要素定義から漏れています。

## 2. 詳細な指摘内容
- 要件定義書 `docs/req-def/requirements.md` L96-104 では、タスク編集関連機能として以下の操作が規定されています：
  - タスクの名前変更、優先度変更
  - 締切日時の変更・解除（L99）
  - コメントの変更
  - タスク状態更新（未着手、進行中、完了）
  - タスク削除（L102-103）
  - タスクピン止め状態更新（L104）
- 一方、`docs/design/screen_design.md` L35 の「タスク編集ポップアップ」構成要素には以下のみが記載されています：
  ```markdown
  タスク名入力欄<br>ステータス選択プルダウン<br>優先度選択プルダウン<br>締切り日時入力欄<br>コメント入力欄<br>「決定」ボタン<br>「キャンセル」ボタン
  ```
- 主な問題点：
  1. **ピン止め切り替えUIの欠落**: 一覧画面やカレンダー日付詳細ポップアップではピン止め操作が可能ですが、詳細編集モーダル（タスク編集ポップアップ）内でピン留めフラグ（`is_pinned`）を切り替える操作要素が存在しません。
  2. **締切日時解除UIの欠落**: 既に設定されている締切日時を解除（NULL化）するための「クリア」ボタンまたは未設定化操作が定義されていません。
  3. **タスク削除UIの欠落**: タスク詳細・編集画面から直接タスクを削除する「削除」ボタン（削除確認ダイアログ呼び出し）が配置されておらず、一覧画面に戻らないと削除できない不便な導線となっています。

## 3. 推奨される修正案
`docs/design/screen_design.md` の「タスク編集ポップアップ」（L35）の遷移先および構成要素を以下のように更新してください：

- **遷移先**:
  ```markdown
  もとの画面<br>タスク削除確認ダイアログ（削除ボタン押下時）
  ```
- **構成要素**:
  ```markdown
  タスク名入力欄<br>ステータス選択プルダウン<br>優先度選択プルダウン<br>締切り日時入力欄（クリア/解除ボタン付き）<br>コメント入力欄<br>「ピン留め」切り替えチェックボックス/トグル<br>「削除」ボタン（確認ダイアログ展開）<br>「決定」ボタン<br>「キャンセル」ボタン
  ```
