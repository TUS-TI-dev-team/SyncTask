# ヘッダー構成要素におけるログイン中ユーザー名表示領域の欠落

- **Status**: Open
- **Severity**: Minor
- **Created At**: 2026-08-18 21:05:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`requirements.md`）において、ユーザー名変更時に画面上の表示名が即座に更新される旨が規定されているにもかかわらず、`docs/design/screen_design.md` のヘッダー構成要素にログイン中ユーザー名の表示領域が定義されていません。

## 2. 詳細な指摘内容
- 要件定義書 `docs/req-def/requirements.md` L41 に以下の記述があります：
  > ユーザー名変更完了後も現在のログインセッションは維持され、画面上の表示名（ユーザー名）が即座に更新される
- しかし、`docs/design/screen_design.md` L66 の「ヘッダー」構成要素には以下のみが記載されています：
  ```markdown
  「ホーム」リンク<br>「タスク」リンク<br>「プロフィール」リンク<br>「ログアウト」リンク
  ```
- ログイン中のユーザーがどのアカウントでログインしているかを常時視認でき、かつユーザー名変更が即座に画面全体に反映されることを担保するためには、ヘッダー（またはプロフィールリンクに付随する領域）にユーザー名表示領域が明記されている必要があります。

## 3. 推奨される修正案
`docs/design/screen_design.md` L66 の「ヘッダー」構成要素を以下のように更新してください：

- **構成要素**:
  ```markdown
  「ホーム」リンク<br>「タスク」リンク<br>ログイン中ユーザー名表示（「プロフィール」リンク兼用またはアバター表示）<br>「ログアウト」ボタン/リンク
  ```
