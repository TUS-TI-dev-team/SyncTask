# ログインセッション有効期限の表記揺れおよびスペースの不整合

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-18 19:55:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書内で、ログインセッションの有効期限に関する期間の表記（「1ヶ月」「43200分(30日 )」「43200分（1ヶ月）」）に表記揺れおよび不自然なスペースが存在しています。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の以下の箇所で表記が分かれています：

1. L193:
```markdown
	- ログイン認証のセッション期限は1ヶ月とする（APIアクセスごとに自動延長される Sliding Expiration 方式）
```

2. L284:
```markdown
    - 有効期限 43200分(30日 )
```

3. L291:
```markdown
    - ユーザーがログイン中にリクエスト（API呼び出し）を行うたびに、セッションの有効期限をアクセス時刻から43200分（1ヶ月）後に自動更新（Sliding Expiration）する。最後のアクセスから43200分経過したセッションを無効（期限切れ）とする
```

- 「1ヶ月」という期間は暦月（28日〜31日）によって日数が変動するため、仕様として厳密に「43200分（= 30日間 = 720時間）」を意味するのであれば、すべての箇所で「43200分（30日間）」として統一することが望ましいです。
- また、L284 の `(30日 )` は閉じ括弧の前に不要な半角スペースが入っておりフォーマットの不整合となっています。

## 3. 推奨される修正案
すべてのセッション有効期限の記述を「43200分（30日間）」に統一してください：

```markdown
<!-- L193 -->
	- ログイン認証のセッション期限は43200分（30日間）とする（APIアクセスごとに自動延長される Sliding Expiration 方式）
```

```markdown
<!-- L284 -->
    - 有効期限 43200分（30日間）
```

```markdown
<!-- L291 -->
    - ユーザーがログイン中にリクエスト（API呼び出し）を行うたびに、セッションの有効期限をアクセス時刻から43200分（30日間）後に自動更新（Sliding Expiration）する。最後のアクセスから43200分経過したセッションを無効（期限切れ）とする
```
