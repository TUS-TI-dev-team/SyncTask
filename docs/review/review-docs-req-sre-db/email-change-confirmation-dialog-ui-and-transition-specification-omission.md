# プロフィール編集画面におけるメールアドレス変更確認ダイアログの構成要素および遷移仕様の欠落

- **Status**: Open
- **Severity**: Minor
- **Created At**: 2026-08-18 21:05:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`docs/design/screen_design.md` の「プロフィール編集画面」の役割・機能欄に「メールアドレスの変更があった場合は、メール送信及びログイン画面へ戻る点についての確認ダイアログを出したのちメール変更手続き（OTP送信）に進む」と記載されていますが、遷移先一覧や構成要素、補足にこの「メールアドレス変更確認ダイアログ」のUI構成およびキャンセル時の遷移先が明記されていません。

## 2. 詳細な指摘内容
- `docs/design/screen_design.md` L57 の「プロフィール編集画面」において：
  - 役割・機能欄: `アカウント情報（ユーザー名、メールアドレス）の入力欄を表示<br>メールアドレスの変更があった場合は、メール送信及びログイン画面へ戻る点についての確認ダイアログを出したのちメール変更手続き（OTP送信）に進む`
  - 遷移先列: `メール変更無し：プロフィール表示画面<br>メール変更あり：アカウント関連/OTP入力画面`
  - 構成要素列: `「ユーザ名」入力欄(デフォルト値として現在のアカウント情報を表示)<br>「メールアドレス」入力欄(デフォルト値として現在のアカウント情報を表示)<br>「キャンセル」ボタン<br>「決定」ボタン`
- 主な問題点：
  - ユーザーがメールアドレスを変更して「決定」を押下した際、確認ダイアログが表示されますが、ダイアログ上に表示する警告メッセージ（「メールアドレスを変更すると現在のログインセッションは破棄され、OTP認証完了後にログイン画面に戻ります。よろしいですか？」等）や、ダイアログ内ボタン（「変更手続きに進む」「キャンセル」）の構成要素が定義されていません。
  - また、ダイアログで「キャンセル」を選択した場合はOTP送信を行わずプロフィール編集画面に留まるべきですが、その遷移フローが遷移先列および補足に記載されていません。

## 3. 推奨される修正案
`docs/design/screen_design.md` の「プロフィール編集画面」（L57）を以下のように更新してください：

- **遷移先**:
  ```markdown
  メール変更無し：プロフィール表示画面<br>メール変更あり（確認ダイアログで「手続きに進む」押下時）：メールアドレス変更/OTP入力画面<br>確認ダイアログで「キャンセル」押下時：プロフィール編集画面に留まる
  ```
- **構成要素**:
  ```markdown
  「ユーザ名」入力欄(デフォルト値として現在のアカウント情報を表示)<br>「メールアドレス」入力欄(デフォルト値として現在のアカウント情報を表示)<br>「決定」ボタン<br>「キャンセル」ボタン<br>メールアドレス変更確認ダイアログ（変更時警告メッセージ、「変更手続きに進む」ボタン、「キャンセル」ボタン）
  ```
