# タスク一覧画面におけるリスト表示とカレンダー表示のUI要素動的切り替え仕様の未定義

- **Status**: Open
- **Severity**: Medium
- **Created At**: 2026-08-18 21:05:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`docs/design/screen_design.md` の「タスク一覧画面」において、リスト表示用UI要素（キーワード・優先度・締切日・ステータス絞り込み、ページネーション）とカレンダー表示用UI要素（月・週表示切替、カレンダーナビゲーション）が同一行の構成要素欄に混在して列挙されており、表示形式（リスト表示 / カレンダー表示）の切り替えに応じたUIコントロールの動的表示・非表示および適用関係が未定義です。

## 2. 詳細な指摘内容
- `docs/design/screen_design.md` L33 のタスク一覧画面構成要素には、以下の要素がフラットに列挙されています：
  ```markdown
  タスク一覧表示欄（リスト表示部 / カレンダー表示部）<br>検索用入力欄（キーワード）<br>優先度絞り込みプルダウン<br>ステータス絞り込みプルダウン<br>締切日絞り込み入力欄<br>「完了タスク表示/非表示」切り替えトグル<br>ページネーション操作UI（前へ/次へボタン、ページ番号）<br>「表示形式切り替え」ボタン（リスト表示 / カレンダー表示）<br>カレンダー表示切替UI（全体表示［月グリッド］ / 週表示）<br>カレンダーナビゲーション（全体表示時:「前月（＜）」「次月（＞）」「今日」ボタン）<br>カレンダーナビゲーション（週表示時:「前週（＜）」「翌週（＞）」「今日」ボタン）<br>「タスク作成」ボタン
  ```
- 主な問題点：
  1. **ページネーションの競合**: カレンダー表示（月グリッド/週表示）は日付セル単位で全タスクをマッピングし、月・週単位のナビゲーションボタンで時間軸を移動するUI構造です。そのため、リスト表示用の「1ページ20件単位のページネーション操作UI」はカレンダー表示時には不要であり、表示するとUI破綻およびユーザー混乱の原因になります。
  2. **検索・絞り込みUIの適用範囲の曖昧さ**: 要件定義書（`requirements.md` L128-140）では検索（キーワード、優先度、締切日、ステータス）は「一覧表示（リスト表示）」のサブセクションに記載されています。「締切日絞り込み（指定日当日までの締切）」や「キーワード検索」がカレンダー表示時にも適用されるのか、あるいはカレンダー表示時は「完了タスク表示切替」のみが有効になるのかが画面設計上定義されていません。

## 3. 推奨される修正案
`docs/design/screen_design.md` の「タスク操作補足」に、表示形式切り替え時におけるUIコントロールの表示・非活性制御仕様を明記してください：

- **表示形式（リスト / カレンダー）切り替え時のUI制御**:
  - **リスト表示時**: 検索バー（キーワード、優先度、ステータス、締切日絞り込み）、完了タスク表示切替トグル、およびページネーション操作UI（上下）を表示する。カレンダー表示切替UI（月/週）およびカレンダーナビゲーション（前月/次月/前週/翌週/今日）は非表示とする。
  - **カレンダー表示時**: カレンダー表示切替UI（全体表示［月］/ 週表示）、カレンダーナビゲーションUI（前月・次月・前週・翌週・今日）、および完了タスク表示切替トグルを表示する。リスト用のページネーション操作UIおよび締切日絞り込み入力欄は非表示とする（※キーワード/優先度/ステータス検索をカレンダーに適用しない場合は検索バーも非表示、またはカレンダー内ハイライト/フィルタとして動作を明確化する）。
