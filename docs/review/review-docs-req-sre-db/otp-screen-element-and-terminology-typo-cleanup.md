# OTP画面の構成要素（送信先メールアドレス表示）の欠落および誤字・用語表記ゆれの是正

- **Status**: Open
- **Severity**: Minor
- **Created At**: 2026-08-18 20:50:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`docs/design/screen_design.md` の各OTP入力画面において、役割・機能や補足で言及されている「送信先メールアドレス表示領域」がテーブルの構成要素列から漏れている点、および複数のタイポ（「OTP発効後」「ホップアップ」）や画面名の表記ゆれが存在します。

## 2. 詳細な指摘内容

1. **構成要素列における送信先メールアドレス表示領域の漏れ**:
   - `アカウント作成/OTP入力画面`（L9）、`パスワードリセット/OTP入力画面`（L11）、`アカウント関連/OTP入力画面`（L58）の「役割・機能」欄および「OTP・セキュリティ操作補足」（L70）では、「送信先情報（始め4文字＋ドメイン名のみ表示、他10文字固定幅マスク）」を表示する仕様が明記されていますが、テーブルの「構成要素」列には記載が漏れています。
2. **タイポ（誤字）**:
   - L9, L11, L58: `OTP発効後5分が経過した場合は`
     - 「発効（法律や条約等の効力が発生すること）」ではなく、「発行（コードが生成・送出されたこと）」であるため、`OTP発行後5分が経過した場合は` が適切です。
   - L9, L11, L58: `ホップアップにて通知し再送を促す。`
     - 正しくは `ポップアップにて通知し再送を促す。` です。
3. **画面名命名規則の不統一**:
   - L58 の画面名が `アカウント関連/OTP入力画面` となっていますが、他のOTP画面（`アカウント作成/OTP入力画面`、`パスワードリセット/OTP入力画面`）の命名体系に合わせ、`メールアドレス変更/OTP入力画面`（または `プロフィール編集/OTP入力画面`）と命名を統一すべきです。

## 3. 推奨される修正案
`docs/design/screen_design.md` において以下を修正してください：

1. 各OTP画面（L9, L11, L58）の「構成要素」列に `送信先メールアドレス表示領域（始め4文字＋ドメイン名のみ表示、他10文字固定幅マスク）` を追記する。
2. L9, L11, L58 の記述内の `OTP発効後` を `OTP発行後` に、`ホップアップ` を `ポップアップ` に修正する。
3. L58 の画面名 `アカウント関連/OTP入力画面` を `メールアドレス変更/OTP入力画面` に統一する。
