# OTPセッションタイムアウト時（パスワードリセット・メールアドレス変更）のリダイレクト先画面の誤記

- **Status**: Open
- **Severity**: Major
- **Created At**: 2026-08-18 20:50:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`docs/design/screen_design.md` において、「パスワードリセット/OTP入力画面」および「アカウント関連/OTP入力画面（メールアドレス変更）」の15分セッション期限切れ時のリダイレクト先が、誤って「アカウント作成画面/情報入力画面」と記載されています。

## 2. 詳細な指摘内容
`docs/design/screen_design.md` の L11 および L58 に以下の記述があります：

1. **パスワードリセット/OTP入力画面（L11）**:
   ```markdown
   15分のOTPセッション期限が切れた場合は自動的にアカウント作成画面/情報入力画面へリダイレクトされる。
   ```
   - パスワードリセット手続きにおいて15分セッションが期限切れとなった場合、本来はパスワードリセットの起点である「パスワードリセット/メールアドレス入力画面」にリダイレクトされるべきです（`requirements.md` L77, L227, L280 参照）。アカウント作成画面へリダイレクトされると、パスワードを忘れて再設定を試みているユーザーが新規登録画面に誘導されてしまい、重大なUX上の混乱・不具合となります。

2. **アカウント関連/OTP入力画面（メールアドレス変更）（L58）**:
   ```markdown
   15分のOTPセッション期限が切れた場合は自動的にアカウント作成画面/情報入力画面へリダイレクトされる。
   ```
   - 要件定義書 `docs/req-def/requirements.md` L51 では以下のように明確に規定されています：
     > OTPのセッション有効期限が切れた場合(セッション発行から15分経過後)はOTPセッションを無効化［物理削除］しアカウント編集用の画面へリダイレクトさせる
   - メールアドレス変更手続き中のセッションタイムアウト時は、アカウント編集の起点である「プロフィール編集画面」（またはプロフィール表示画面）へリダイレクトされるべきであり、アカウント作成画面へリダイレクトするのは誤記です。

## 3. 推奨される修正案
`docs/design/screen_design.md` の L11 および L58 の「役割・機能」欄の記述を以下のように修正してください：

1. **パスワードリセット/OTP入力画面（L11）**:
   ```markdown
   15分のOTPセッション期限が切れた場合は自動的にパスワードリセット/メールアドレス入力画面へリダイレクトされる。
   ```

2. **アカウント関連/OTP入力画面（L58）**:
   ```markdown
   15分のOTPセッション期限が切れた場合は自動的にプロフィール編集画面へリダイレクトされる。
   ```
