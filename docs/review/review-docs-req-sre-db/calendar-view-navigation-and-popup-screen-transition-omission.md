# カレンダー全体表示ナビゲーションの構成要素漏れおよび日付詳細ポップアップの遷移定義不備

- **Status**: Open
- **Severity**: Medium
- **Created At**: 2026-08-18 20:50:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`docs/design/screen_design.md` のタスク一覧画面において、カレンダー全体表示（月表示）時のナビゲーションボタン（「前月」「次月」「今日」）が構成要素一覧から欠落しており週ナビゲーションのみが記載されている点、および画面遷移先列に「日付詳細ポップアップ」が明記されていない問題があります。

## 2. 詳細な指摘内容
`docs/design/screen_design.md` のタスク一覧画面（L33）の定義において以下の不備があります：

1. **構成要素の欠落**:
   - L33 の構成要素列には `カレンダー週ナビゲーション（「前週（＜）」「翌週（＞）」「今日」ボタン）` のみが記載されています。
   - しかし、補足（L46）および要件定義書（`requirements.md` L148-L153）には、カレンダーの全体表示（月グリッド）において「前月（＜）」「次月（＞）」「今日」ボタンによる月ナビゲーションを提供する旨が記載されています。全体表示用のナビゲーション操作UIが構成要素一覧から漏れています。
2. **画面遷移先定義の漏れ**:
   - L33 の遷移先列には `タスク作成ポップアップ<br>タスク編集ポップアップ` のみが記載されています。
   - 一方、補足（L47-L50）には、カレンダーグリッドの日付セルをクリックした際にモーダル表示される「日付詳細ポップアップ」が詳細に定義されています。このポップアップはタスクステータス直接更新や該当日のタスク作成・編集への遷移ハブとなる重要なUIであるため、画面遷移先列に明記されるべきです。

## 3. 推奨される修正案
`docs/design/screen_design.md` の「タスク一覧画面」（L33）を以下のように更新してください：

- **遷移先**:
  ```markdown
  タスク作成ポップアップ<br>タスク編集ポップアップ<br>日付詳細ポップアップ（カレンダーセルクリック時）
  ```
- **構成要素**:
  ```markdown
  タスク一覧表示欄（リスト表示部 / カレンダー表示部）<br>検索用入力欄（キーワード）<br>優先度絞り込みプルダウン<br>ステータス絞り込みプルダウン<br>締切日絞り込み入力欄<br>「完了タスク表示/非表示」切り替えトグル<br>ページネーション操作UI（前へ/次へボタン、ページ番号）<br>「表示形式切り替え」ボタン（リスト表示 / カレンダー表示）<br>カレンダー表示切替UI（全体表示［月グリッド］ / 週表示）<br>カレンダーナビゲーションUI（全体表示時:「前月（＜）」「次月（＞）」「今日」 / 週表示時:「前週（＜）」「翌週（＞）」「今日」）<br>「タスク作成」ボタン
  ```
