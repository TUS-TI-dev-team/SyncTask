# GET tasks における due_date 絞り込みのタイムゾーン（JST）および未設定（NULL）タスク除外仕様の未定義

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-17 16:53:00
- **Target Files**:
  - [04_tasks.md](docs/design/api_design/04_tasks.md)

## 1. 問題の概要
`GET tasks` API のクエリパラメータ `due_date` の動作説明において、「指定日 23:59:59 までのタスクを検索」と記載されていますが、適用されるタイムゾーン（JST `+09:00`）の補足、締切日時未設定（`due_datetime: null`）タスクの除外ルール、および過去の期限超過タスクが含まれる旨の明確な仕様記述が不足しています。

## 2. 詳細な指摘内容
要件定義書（`docs/req-def/requirements.md` の「タスク検索（and検索）」セクション）では、ヒアリングに基づき以下のように確定されています：
> 「指定日当日までの締め切り（〜指定日 23:59:59 JST）に該当する締切日時を持つタスクを検索（過去の未完了タスク等を含める、未設定タスクは除外、未指定時は絞り込みを行わない）」

一方、`04_tasks.md` L19 の `due_date` パラメータ定義表には以下のようにのみ記載されています：
> `due_date` | string | × | - | 締切日絞り込み（`YYYY-MM-DD`。指定日 23:59:59 までのタスクを検索）

この記述では以下の点が不明確であり、フロントエンドとバックエンド間で実装不一致が生じる恐れがあります：
1. **タイムゾーンの基準**: `23:59:59` が日本標準時（JST `+09:00`）での時刻（`YYYY-MM-DD 23:59:59+09:00`）である旨が明記されていません。
2. **締切未設定（NULL）タスクの扱い**: `due_datetime` が `null` のタスクは対象から除外（`due_datetime IS NOT NULL`）される仕様が明記されていません。
3. **範囲検索の理解**: 「指定日当日だけの検索（`00:00:00`〜`23:59:59`）」と誤認される可能性があり、過去の期限超過タスクを含めた「〜指定日 23:59:59 JST」までの範囲検索である旨を強調する必要があります。

## 3. 推奨される修正案
`04_tasks.md` L19 の `due_date` パラメータ説明文を以下のように修正してください。

```markdown
| `due_date` | string | × | - | 締切日絞り込み（`YYYY-MM-DD`。指定日 23:59:59 JST までの締切日時を持つタスクを検索。過去の未完了・期限超過タスクを含み、締切日時未設定 `null` のタスクは除外。未指定時は絞り込みを行わない） |
```
