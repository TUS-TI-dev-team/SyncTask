# GET tasks の due_date 絞り込みにおける過去の完了済みタスク除外条件の未定義

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-17 17:15:00
- **Target Files**:
  - [04_tasks.md](docs/design/api_design/04_tasks.md)

## 1. 問題の概要
`GET tasks` (3.3.1 節) のクエリパラメータ `due_date`（締切日絞り込み）の説明において、「指定日 23:59:59 JST までの締切日時を持つタスクを検索。過去の未完了・期限超過タスクを含み...」と規定されていますが、指定日より前（過去）の締切日時を持つタスクのうち「完了済み (`status = completed`)」のタスクを検索対象から除外するフィルタ条件式が具体的に明記されていません。

## 2. 詳細な指摘内容
1. **過去の完了済みタスクの誤混入リスク**:
   - `04_tasks.md` L19 の説明文通りにバックエンド側で `due_datetime <= 'YYYY-MM-DD 23:59:59+09:00'` の単純な範囲検索SQLを生成した場合、指定日当日のタスクだけでなく、過去数ヶ月〜数年間に完了したすべての過去タスクまで当日の `due_date` 検索結果に含まれてしまう実装不具合が発生します。
2. **条件分岐の曖昧さ**:
   - 仕様記述の「過去の未完了・期限超過タスクを含み」という文脈は、以下のように明確な論理条件として仕様書に書き下される必要があります：
     - **指定日当日**（`YYYY-MM-DD 00:00:00+09:00 <= due_datetime <= YYYY-MM-DD 23:59:59+09:00`）: 指定されたステータス/`include_completed` フィルタに従って全タスク（完了含む）を対象とする。
     - **指定日より過去**（`due_datetime < YYYY-MM-DD 00:00:00+09:00`）: 未完了タスク（`status != 'completed'`）のみを対象とし、完了済みタスクは常に除外する。

## 3. 推奨される修正案
`04_tasks.md` L19 の `due_date` パラメータ説明欄およびレスポンス注記に、過去タスクのステータス絞り込み条件（`due_datetime < YYYY-MM-DD 00:00:00 JST` の範囲については `status != 'completed'` の未完了タスクのみを抽出対象とし、過去の完了済みタスクは除外する旨）を明記してください。

## 修正完了報告

- **Resolved At**: 2026-08-17 17:18:00
- **Status**: Resolved

### 実施した修正内容
`04_tasks.md` 3.3.1 節 (`GET tasks`) の `due_date` パラメータ説明を更新し、指定日当日 (`YYYY-MM-DD 00:00:00+09:00 <= due_datetime <= 23:59:59+09:00`) の全タスク、および指定日より過去 (`due_datetime < 00:00:00+09:00`) の未完了タスク (`status != 'completed'`) を抽出対象とし、過去の完了済みタスクは常に除外することを明記しました。
