# パスワードリセット/OTP入力画面における「戻る」ボタンの遷移先記載漏れ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-14 20:53:30
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`screen_design.md` の「パスワードリセット/OTP入力画面」の構成要素には「`「戻る」ボタン`」が存在しますが、画面一覧テーブルの「遷移先」カラムには `パスワード再設定画面`（認証成功時）しか記載されておらず、「戻る」ボタン押下時の中断・キャンセル遷移先が欠落しています。

## 2. 詳細な指摘内容
1. `アカウント作成/OTP入力画面`（Line 9）では、遷移先カラムに「`決定（認証成功）：ホーム画面<br>戻る・キャンセル：ログイン画面`」と成功時およびキャンセル時の両方の遷移先が明記されています。
2. 一方で `パスワードリセット/OTP入力画面`（Line 11）では、構成要素に「`「戻る」ボタン`」が記載されているにも関わらず、遷移先カラムには `パスワード再設定画面` のみが記載されています。
3. 「戻る」ボタンを押した際に `パスワードリセット/メールアドレス入力画面`（または `ログイン画面`）に戻る画面遷移が設計書上で明確になっておらず、遷移仕様の不整合および考慮漏れとなっています。

## 3. 推奨される修正案
`パスワードリセット/OTP入力画面`（Line 11）の「遷移先」カラムを以下のように修正してください：

```markdown
| パスワードリセット/OTP入力画面 | 送信先情報... | 決定（認証成功）：パスワード再設定画面<br>戻る・キャンセル：パスワードリセット/メールアドレス入力画面 | OTP入力欄... |
```

## 修正完了報告

- **Resolved At**: 2026-08-14 20:58:00
- **Status**: Resolved

### 実施した修正内容
ユーザー確認方針（`パスワードリセット/メールアドレス入力画面` へ戻る）に基づき、`screen_design.md` の「パスワードリセット/OTP入力画面」の遷移先カラムを「決定（認証成功）：パスワード再設定画面<br>戻る・キャンセル：パスワードリセット/メールアドレス入力画面」に修正しました。
