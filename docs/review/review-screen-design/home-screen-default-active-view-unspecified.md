# ホーム画面アクセス時の初期表示タスクビュー（デフォルトアクティブ）の未指定

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 23:32:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
`screen_design.md` の「ホーム画面」では、「高優先度タスク一覧表示」「締切間近タスク表示」「ピン止めタスク表示」の3つのタスクビューを切り替えて表示できる仕様となっていますが、ユーザーがホーム画面へ初期アクセスした際にどのタスクビューがデフォルトで選択・表示されるのかが明記されていません。

## 2. 詳細な指摘内容
1. `screen_design.md` の「ホーム画面」（Line 18）の役割・機能欄には以下のように記載されています：
   - 「高優先度タスク一覧表示、締切間近タスク表示、ピン止めタスク表示の3つのタスクビューを、切り替えて表示できるようにする」
2. しかし、画面初期描画時にどのタスクビューがアクティブ（選択中）となるのかのデフォルト状態が指定されておらず、実装者によって挙動のブレが生じる可能性があります（一般的には「高優先度タスク一覧表示」または「締切間近タスク表示」が初期選択となることが想定されます）。

## 3. 推奨される修正案
`screen_design.md` の「ホーム画面」の役割・機能欄または構成要素欄に、初期アクセス時のデフォルト選択タスクビュー（例: 「（※初期表示時は『高優先度タスク一覧表示』が選択状態）」）を明記してください。
