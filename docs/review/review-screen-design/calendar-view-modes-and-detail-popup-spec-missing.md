# カレンダー表示における表示モード切替（全体/週）・週ナビゲーション・日付詳細ポップアップの設計記載不足

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-16 23:32:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）ではカレンダー表示に関して「全体表示（5〜6週グリッド）」と「週表示（7日間）」の2種類の表示形式の切り替え、週ナビゲーション、セル上でのステータス直接変更、および日付クリック時の「日付詳細ポップアップ」の詳細な機能要件が規定されていますが、`screen_design.md` の「タスク一覧画面」および補足説明では単に「表示形式切り替えボタン」とあるのみで、カレンダー表示時の表示モード切替UIや重要なモーダルコンポーネントである「日付詳細ポップアップ」の定義が欠落しています。

## 2. 詳細な指摘内容
1. `requirements.md`（機能要件 カレンダー表示 Line 138-154）には以下のように規定されています：
   - 「表示形式は下記の2パターンを選択できる」
     - 「(default)全体表示: 日-土曜日（日曜日始まり）にて、対象月の初日（1日）から末日までの全日程が確実に含まれる週（5週間または6週間）を表示。前週/前月、次週/次月操作等」
     - 「週表示: 日-土曜日（日曜日始まり）にて現在または指定日を含む週（7日間）を表示。「前週（＜）」「翌週（＞）」ボタンや「今日」ボタンを提供」
   - 「それぞれの表示形式にてある日にちをクリックするとその日のタスクを詳細に表示するポップアップを表示する」
     - ポップアップ内の機能: 該当日のタスク一覧表示（タイトル・締切時刻・ステータス・優先度）、タスクステータス直接変更（未着手/進行中/完了）、タスク詳細/編集画面への遷移リンク、該当日を締切日とする新規タスク作成ボタン
   - 「カレンダー画面（全体表示・週表示の日付セル上）および日付詳細ポップアップの双方において、各タスクのステータスを直接変更可能とする（日付セル上のタスク操作時はポップアップ展開イベントを抑止する）」
2. しかし、`screen_design.md` の「タスク一覧画面」（Line 24）の構成要素には「`「表示形式切り替え」ボタン`」のみが記載されており、カレンダー表示時の「全体表示/週表示切り替えUI」「週ナビゲーション（前週/翌週/今日ボタン）」、および独立した操作・遷移を持つ「日付詳細ポップアップ」のコンポーネント定義が一切記載されていません。
3. これにより、カレンダー画面からポップアップを開いた際の画面仕様やポップアップからのタスク作成・編集への画面遷移導線が画面設計書上で不明確になっています。

## 3. 推奨される修正案
1. `screen_design.md` の「タスク一覧画面」または「タスク関連」の別表/コンポーネントセクションとして、カレンダー表示時および「日付詳細ポップアップ」のUI構成要素と遷移先を定義してください：
   - カレンダー表示用UI:
     - 全体表示（月グリッド）/ 週表示 切り替えスイッチ
     - 週ナビゲーション（「前週（＜）」「翌週（＞）」「今日」ボタン）
     - カレンダーグリッドセル（タスクステータス直接変更UI付き、完了タスク打消し線表示）
   - 日付詳細ポップアップ（モーダルコンポーネント）:
     - 構成要素: 該当日付表示、タスク一覧表示欄（タイトル、締切時刻、優先度、ステータス変更UI）、タスククリック時「タスク編集画面」へのリンク、該当日締切「新規タスク作成」ボタン、閉じるボタン
     - 遷移先: タスク編集画面、タスク作成画面（該当日付を締切日に事前入力）
2. 「タスク操作補足」に、日付セル上のタスク操作時はポップアップ展開イベントを抑止（Stop Propagation）する仕様を明記してください。

### 実施した修正内容
ユーザーヒアリングでの確認結果に基づき、`screen_design.md` の「タスク一覧画面」の構成要素欄に「カレンダー表示切替UI（全体表示［月グリッド］ / 週表示）」「カレンダー週ナビゲーション（『前週（＜）』『翌週（＞）』『今日』ボタン）」を追加しました。また、「タスク操作補足」にカレンダー表示モード（全体表示/週表示）の仕様、日付詳細ポップアップ（モーダル）の構成要素（タスク一覧、ステータス変更UI、タスク編集画面リンク、新規タスク作成ボタン、閉じるボタン）および遷移先、日付セル上でのステータス直接変更操作時のポップアップ展開抑止仕様を明記しました。
