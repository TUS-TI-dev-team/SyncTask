# ヘッダーコンポーネントにおける未ログイン・ログイン状態に応じた表示切り替え仕様の記載漏れ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-14 20:53:30
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`screen_design.md` の「ヘッダー・フッター」セクションにおいて、ヘッダーの構成要素に「`「ホーム」リンク<br>「タスク」リンク<br>「プロフィール」リンク<br>「ログアウト」リンク`」が定義されていますが、未ログイン状態（ログイン画面や会員登録画面）とログイン状態に応じたナビゲーション表示切り替え仕様の記載が漏れています。

## 2. 詳細な指摘内容
1. `screen_design.md` Line 48 のヘッダー構成要素には各ナビゲーションリンクおよびログアウトリンクが記載されています。
2. ログイン前の画面（ログイン画面、アカウント作成/情報入力画面、パスワードリセット画面等）においてこれらのリンクが表示されると、ログインしていないユーザーが認証保護領域への遷移を試みたり画面表示の不整合を引き起こします。
3. ヘッダー共通部品としての「ログイン状態判定による表示・非表示の制御仕様」が明記されていません。

## 3. 推奨される修正案
ヘッダーの「役割・機能」または「構成要素」欄（Line 48）に以下の補足説明を追加してください：

```markdown
| ヘッダー | 未ログイン画面およびログイン後画面の上部に表示<br>※未ログイン時は各ナビゲーションリンクおよびログアウトリンクを非表示（ロゴ表示のみ）とし、ログイン状態時のみ各リンクを表示する。 | ホーム<br>タスク一覧画面<br>プロフィール表示画面<br>ログアウト | 「ホーム」リンク<br>「タスク」リンク<br>「プロフィール」リンク<br>「ログアウト」リンク |
```
