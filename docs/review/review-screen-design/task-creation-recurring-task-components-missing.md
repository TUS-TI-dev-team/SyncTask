# タスク作成画面における繰り返しタスク（即時一括生成）用UI構成要素の記載漏れ

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-16 23:32:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）ではタスク作成機能の主要要件として「期間と曜日を指定し、その範囲内で毎週タスクを自動作成できる（即時一括生成方式）」が明確に規定されていますが、`screen_design.md` の「タスク作成画面」の構成要素欄には単一タスク作成用の入力項目のみが記載されており、繰り返しタスク作成を行うためのUI構成要素（繰り返し設定トグル/チェックボックス、期間指定入力欄、カレンダーピッカー、曜日選択UI等）が完全に欠落しています。

## 2. 詳細な指摘内容
1. `requirements.md`（機能要件 タスク管理 Line 83-92）には以下のように規定されています：
   - 「期間と曜日を指定し、その範囲内で毎週タスクを自動作成できる（即時一括生成方式）」
   - 「期間指定: 開始日と終了日をそれぞれYYYY/MM/DD形式で入力（テキスト入力またはポップアップ表示のカレンダーから選択可能）」
   - 「曜日指定: 『月、火、水、木、金、土、日』より1つまたは複数選択可能（1つ以上選択必須）」
   - 「最大期間は1年間（最大52週）以内、かつ計算される生成タスク数は1件以上100件まで」
2. しかし、`screen_design.md` の「タスク作成画面」（Line 25）の構成要素は以下の通りとなっています：
   - `タスク名入力欄<br>優先度選択プルダウン<br>締切り日時入力欄<br>コメント入力欄<br>「決定」ボタン<br>「キャンセル」ボタン`
3. 繰り返しタスク作成を有効化する切り替えコントロール、期間（開始日・終了日）入力欄、曜日選択チェックボックスなどのUI構成要素が一切定義されておらず、実装者がUI設計およびフロントエンド実装を行う際に仕様漏れが生じる重大な不整合となっています。
4. なお、タスク編集画面では繰り返しタスクの一括連動更新機能は提供せず個別編集のみとなる仕様（`requirements.md` Line 92）であるため、タスク作成画面にのみ繰り返し設定UIが存在する点についても画面設計上で明記する必要があります。

## 3. 推奨される修正案
1. `screen_design.md` の「タスク作成画面」（Line 25）の構成要素欄に繰り返しタスク作成用UIを追加してください：
   - 「繰り返し作成」切り替えトグル/チェックボックス
   - 期間指定（開始日・終了日）入力欄（カレンダーピッカー付き）
   - 曜日選択チェックボックス（月〜日）
   - 締切時刻指定欄（任意、省略時23:59 JST）
2. 役割・機能欄および「タスク操作補足」に、期間と曜日を指定した即時一括生成（最大100件/52週）のUI動作、およびタスク編集画面では個別タスクの編集のみを対象とする旨を補足明記してください。

## 修正完了報告

- **Resolved At**: 2026-08-16 23:42:00
- **Status**: Resolved

### 実施した修正内容
ユーザーヒアリングでの確認結果に基づき、`screen_design.md` の「タスク作成画面」の構成要素欄に「『繰り返し作成』切り替えトグル/チェックボックス」「期間指定（開始日・終了日）入力欄（カレンダーピッカー付き）」「曜日選択チェックボックス（月〜日）」を追加しました。また、タスク作成画面の役割・機能欄および「タスク操作補足」に即時一括生成方式（最大100件/52週）の仕様、およびタスク編集画面では個別タスクの編集のみを対象とする旨を明記しました。
