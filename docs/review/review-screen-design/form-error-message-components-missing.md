# 各種フォーム入力画面におけるエラーメッセージ・バリデーション表示領域の記載漏れ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 23:32:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
`screen_design.md` に記載されている各種入力フォーム（ログイン画面、アカウント作成画面、パスワードリセット関連画面、プロフィール編集画面、パスワード変更画面、アカウント削除画面、タスク作成/編集画面等）において、バリデーションエラーや認証失敗・ロックアウト等のシステム通知を表示するためのUI領域（インラインエラー表示領域、アラートバナー等）が構成要素欄および補足欄に定義されていません。

## 2. 詳細な指摘内容
1. `requirements.md`（非機能要件 セキュリティ等）では、入力値バリデーション違反（ユーザー名・パスワード・メールアドレス・タスク名等の文字数・形式エラー）、認証失敗、ロックアウト、セッションタイムアウト、生成件数超過エラーなど、ユーザーへフィードバックを返す仕様が多数定義されています。
2. しかし、`screen_design.md` の各入力画面の構成要素欄には入力欄とボタン・リンクのみが記載されており、エラー通知・バリデーションメッセージを表示するUI領域（各入力欄下部のインラインエラー表示やフォーム上部のアラートメッセージ欄）が明記されていません。
3. 画面設計書としてエラー表示領域を定義しておくことで、UIコンポーネント設計および画面レイアウト設計の一貫性を担保できます。

## 3. 推奨される修正案
各入力画面の構成要素に「エラーメッセージ表示領域（インライン/アラート）」を追記するか、または画面設計書の共通仕様補足（「OTP・セキュリティ操作補足」または「共通UI・レイアウト補足」セクション）に以下の記述を追加してください：

```markdown
### 共通UI・エラー表示補足
- 各種入力フォーム画面（ログイン、新規登録、パスワードリセット、プロフィール編集、パスワード変更、アカウント削除、タスク作成・編集等）においては、入力バリデーションエラーやAPIエラー（認証失敗・ロックアウト・サーバーエラー等）を明示するためのエラーメッセージ表示領域（各入力欄下部のインラインエラー表示およびフォーム上部のアラートバナー領域）を備える。
```
