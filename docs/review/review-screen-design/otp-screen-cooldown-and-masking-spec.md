# OTP入力画面における送信先マスク表示および60秒再送クールダウン UI 仕様の記載漏れ

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-14 20:28:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）で規定されている「OTP送信先メールアドレスのマスク表示」や「再送信ボタンの60秒クールダウン（非活性・カウントダウン表示）」について、`screen_design.md` の各OTP画面における構成要素および画面説明での記載が一部不足しています。

## 2. 詳細な指摘内容
1. **マスク表示の記載ばらつき**:
   - 「パスワードリセット/OTP入力画面」(Line 11) には「始め4文字, ドメインのみ表示し他はマスク...」と詳細な記述があります。
   - 一方、「アカウント作成/OTP入力画面」(Line 9) は「xx@xx.com にメールを送信しましたという情報」、および「アカウント関連/OTP入力画面」(Line 39) に至ってはマスク表記や送信先案内テキストに関する記載そのものが漏れています。
2. **再送クールダウン表示**:
   - `requirements.md`（セキュリティ OTP要件 Line 197）では「直前の送信から60秒間のクールダウン期間を設定し、画面上の再送ボタンを非活性化（カウントダウン表示）として連投を制限する」と規定されています。
   - しかし `screen_design.md` の全OTP入力画面の構成要素において、「再送信」ボタンが単に配置されているのみで、60秒間のボタン非活性化・カウントダウンタイマー表示に関するUI仕様が補足されていません。

## 3. 推奨される修正案
1. 各OTP画面（「アカウント作成/OTP入力画面」「パスワードリセット/OTP入力画面」「アカウント関連/OTP入力画面」）の構成要素または補足欄に、共通して以下を明記してください：
   - 送信先案内表示（始め4文字＋ドメイン表示、それ以外は10文字の固定幅マスク表記）。
   - 「再送信」ボタンの60秒クールダウン仕様（送信直後はボタンを非活性化し、60秒間のカウントダウンを表示するUI制御）。

`screen_design.md` の各OTP入力画面（アカウント作成、パスワードリセット、アカウント関連）および「OTP・セキュリティ操作補足」において、送信先メールアドレスの固定幅マスク表記規則および「再送信」ボタン押下後の60秒クールダウン（ボタン非活性・カウントダウンタイマー表示）仕様を明確に統一追記しました。
