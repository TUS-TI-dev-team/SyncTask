# タスク一覧画面における詳細検索・絞り込みフィルタ構成要素の記載不足

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-14 20:53:30
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）ではキーワード・優先度・締切日・ステータスの4つの検索・絞り込み軸が規定されていますが、`screen_design.md` の「タスク一覧画面」の構成要素には「`検索用入力欄`」と一括でしか記載されておらず、各種フィルタUIパーツが記載不足となっています。

## 2. 詳細な指摘内容
1. 要件定義書（`requirements.md` L109-L120）では以下のタスク検索（and検索）機能が要求されています：
   - キーワード検索（タスク名・コメント部分一致）
   - 優先度絞り込み（高・中・低）
   - 締切日絞り込み（〜指定日 23:59:59 JST）
   - タスクステータス絞り込み（未着手・進行中・完了）
2. しかし `screen_design.md` の「タスク一覧画面」（Line 24）の構成要素には「`検索用入力欄`」のみが記載されており、優先度ドロップダウン、締切日選択欄、ステータスドロップダウン等のUIコンポーネントの記載が欠落しています。
3. これにより、フロントエンド実装時にキーワード検索用の単一テキスト入力のみが作成され、要件を満たすフィルタ機能が実装されないリスクが生じます。

## 3. 推奨される修正案
「タスク一覧画面」（Line 24）の構成要素欄を以下のように具体化・追記してください：

```markdown
- 修正前: タスク一覧表示欄<br>検索用入力欄<br>「完了タスク表示/非表示」切り替えトグル...
+ 修正後: タスク一覧表示欄<br>検索用入力欄（キーワード）<br>優先度絞り込みプルダウン<br>締切日絞り込み入力欄<br>ステータス絞り込みプルダウン<br>「完了タスク表示/非表示」切り替えトグル...
```
