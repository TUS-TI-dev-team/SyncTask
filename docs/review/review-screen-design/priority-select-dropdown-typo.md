# タスク作成・編集画面における「優先度選択トグルダウン」の用語誤り（タイポ）

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-14 20:53:30
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`screen_design.md` の「タスク作成画面」および「タスク編集画面」の構成要素において、優先度選択UIの用語として「`優先度選択トグルダウン`」という誤ったタイポ・標準的でない用語が記載されています。

## 2. 詳細な指摘内容
1. Line 25（タスク作成画面）および Line 26（タスク編集画面）の構成要素欄に「`優先度選択トグルダウン`」と記載されています。
2. 優先度（高、中、低）を1つ選択する一般的なUIコンポーネントは「`ドロップダウン`」（プルダウン / Select）であり、「`トグルダウン`」はタイポまたは不適切な造語です。
3. トグルスイッチなのかドロップダウンメニューなのか実装時に混同や混乱を生む恐れがあります。

## 3. 推奨される修正案
Line 25 および Line 26 の構成要素欄にある「`優先度選択トグルダウン`」を「`優先度選択ドロップダウン`」へ修正してください。

```markdown
- 修正前: タスク名入力欄<br>優先度選択トグルダウン<br>締切り日時入力欄...
+ 修正後: タスク名入力欄<br>優先度選択プルダウン<br>締切り日時入力欄...
```

## 修正完了報告

### 実施した修正内容
ユーザー指定方針に基づき、`screen_design.md` の「タスク作成画面」および「タスク編集画面」における誤表記「優先度選択トグルダウン」を「優先度選択プルダウン」へ修正しました。
