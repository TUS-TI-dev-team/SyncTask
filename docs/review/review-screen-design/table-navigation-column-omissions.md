# 画面一覧テーブルにおける遷移先カラムの記載漏れ・不整合

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-14 20:45:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`screen_design.md` 内の画面一覧テーブルにおいて、「プロフィール編集画面」からのアカウント削除画面への遷移漏れ、および「アカウント作成/情報入力画面」の非現実的な遷移先が残されている問題が確認できます。

## 2. 詳細な指摘内容
1. **プロフィール編集画面 (Line 39)**:
   - 構成要素欄に「『アカウント削除』ボタン（アカウント削除/パスワード再認証画面へ遷移）」が追加されましたが、テーブルの「遷移先」カラムには `メール変更無し：プロフィール表示画面<br>メール変更あり：アカウント関連/OTP入力画面` のみが書かれており、「アカウント削除/パスワード再認証画面」が遷移先カラムから漏れています。
2. **アカウント作成/情報入力画面 (Line 8)**:
   - 「遷移先」に「ホーム画面」が含まれています。新規作成時、情報入力画面から直接ホーム画面へ到達するルートはなく、必ず「アカウント作成/OTP入力画面」を経由してOTP認証を完了する必要があります。

## 3. 推奨される修正案
1. 「プロフィール編集画面」(Line 39) の遷移先カラムに「アカウント削除：アカウント削除/パスワード再認証画面」を追加してください。
2. 「アカウント作成/情報入力画面」(Line 8) の遷移先カラムから「ホーム画面」を削除し、「アカウント作成/OTP入力画面」「ログイン画面（キャンセル時）」として整理してください。
