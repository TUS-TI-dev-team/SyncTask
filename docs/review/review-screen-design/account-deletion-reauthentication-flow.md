# アカウント削除時のパスワード再認証画面および連続失敗時のセッション破棄仕様の定義漏れ

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-14 20:28:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）では、アカウント削除時にパスワード再認証を要求し、5回連続失敗時にセッションを破棄してログイン画面にリダイレクトするセキュリティ仕様が定められていますが、`screen_design.md` では単に「ポップアップで確認ダイアログを出す」等の記述にとどまり、認証画面構成や連続失敗時のリダイレクト・セッション破棄仕様の定義が漏れています。

## 2. 詳細な指摘内容
1. `requirements.md`（機能要件 アカウントの削除 Line 52, セキュリティ パスワード変更時およびアカウント削除時 Line 181-182）には以下のように規定されています：
   - 「確認ダイアログ + パスワード再認証要。5回連続でパスワード再認証に失敗した場合はログインセッションを破棄［物理削除］してログイン画面にリダイレクトする」
2. `screen_design.md` の「プロフィール表示画面」(Line 37) および「プロフィール編集画面」(Line 38) では：
   - プロフィール表示画面: 「アカウント削除ボタンも配置（ポップアップで確認ダイアログを出す）」
   - プロフィール編集画面: 「『アカウント削除』ボタンからアカウント削除ができる」
   と記載されており、パスワード再認証入力欄の配置、および5回連続失敗時の「セッション破棄・ログイン画面へのリダイレクト」といったセキュリティ挙動・画面遷移が画面仕様書上に明確に示されていません。

## 3. 推奨される修正案
1. 「アカウント削除/パスワード再認証画面」（またはモーダルダイアログ）として独立した画面設計項目を追加するか、画面テーブル・補足事項に以下の要素・動作を明確に定義してください：
   - 構成要素：アカウント削除確認メッセージ、現在のパスワード入力欄、「削除実行」ボタン、「キャンセル」ボタン。
   - 遷移先・挙動：
     - パスワード認証成功時：アカウント削除処理を実行し、セッション破棄の上でログイン画面へ遷移。
     - パスワード認証5回連続失敗時：セッションを即座に破棄（物理削除）し、エラーメッセージを表示の上ログイン画面にリダイレクト。
