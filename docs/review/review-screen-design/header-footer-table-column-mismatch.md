# ヘッダー・フッターテーブルにおけるテーブルヘッダーとデータ行のカラム数不一致・Markdown構文崩れ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 00:22:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`screen_design.md` の「ヘッダー・フッター」セクションにある Markdown テーブルにおいて、テーブル見出し（ヘッダー行）のカラム数が3列（`部品名` / `遷移先` / `構成要素`）であるのに対し、ヘッダーのデータ行が4列（`役割・機能` 相当のテキストが挿入された状態）、フッターのデータ行が3列となっており、Markdown テーブルの構文崩れおよびカラム定義の不整合が発生しています。

## 2. 詳細な指摘内容
1. `screen_design.md` Line 46-49 の定義は以下のようになっています：
   ```markdown
   | 部品名 | 遷移先 | 構成要素 |
   | --- | --- | --- |
   | ヘッダー | 未ログイン画面およびログイン後画面の上部に表示<br>※未ログイン時は各ナビゲーションリンクおよびログアウトリンクを非表示（ロゴ表示のみ）とし、ログイン状態時のみ各リンクを表示する。 | ホーム<br>タスク一覧画面<br>プロフィール表示画面<br>ログアウト | 「ホーム」リンク<br>「タスク」リンク<br>「プロフィール」リンク<br>「ログアウト」リンク |
   | フッター | なし | なし |
   ```
2. 見出し行は3カラム（`| 部品名 | 遷移先 | 構成要素 |`）ですが、ヘッダーの行には「未ログイン画面および...（役割・機能に相当）」が含まれて4セル存在し、フッターの行には3セルしか存在しません。
3. このため、Markdown レンダラーによって列ズレやパースエラーが発生し、他のセクションのテーブル（`| 画面名 | 役割・機能 | 遷移先 | 構成要素 |`）ともテーブル構造の整合性が取れていません。

## 3. 推奨される修正案
「ヘッダー・フッター」テーブルの見出し行を他テーブルと同様に4列（`| 部品名 | 役割・機能 | 遷移先 | 構成要素 |`）へと統一し、フッターのデータ行も4列形式に修正してください：

```markdown
| 部品名 | 役割・機能 | 遷移先 | 構成要素 |
| --- | --- | --- | --- |
| ヘッダー | 未ログイン画面およびログイン後画面の上部に表示<br>※未ログイン時は各ナビゲーションリンクおよびログアウトリンクを非表示（ロゴ表示のみ）とし、ログイン状態時のみ各リンクを表示する。 | ホーム<br>タスク一覧画面<br>プロフィール表示画面<br>ログアウト（ログイン画面へ遷移） | 「ホーム」リンク<br>「タスク」リンク<br>「プロフィール」リンク<br>「ログアウト」リンク |
| フッター | 画面下部共通フッター（特記事項なし） | なし | なし |
```
