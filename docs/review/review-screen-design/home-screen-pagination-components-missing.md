# ホーム画面の各タスクビューにおけるページネーションUI構成要素の記載漏れ

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-16 23:32:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）ではホーム画面に提供される3つのタスクビュー（高優先度タスク表示、締切間近タスク表示、ピン止めタスク表示）すべてにおいて「ページネーション: 1ページあたり20件表示」が明確に規定されていますが、`screen_design.md` の「ホーム画面」の構成要素欄にはページネーション操作UI（前へ/次へボタン、ページ番号表示等）が記載されていません。

## 2. 詳細な指摘内容
1. `requirements.md`（機能要件 タスク表示 Line 107, 112, 117）には以下のように規定されています：
   - 「優先タスク表示: ページネーション: 1ページあたり20件表示」
   - 「締切間近タスク表示: ページネーション: 1ページあたり20件表示」
   - 「ピン止めタスク表示: ページネーション: 1ページあたり20件表示」
2. 一方、`screen_design.md` の「タスク一覧画面」（Line 24）には「`ページネーション操作UI（前へ/次へボタン、ページ番号）`」が構成要素として記載されているものの、「ホーム画面」（Line 18）の構成要素欄には以下の通りページネーション操作UIが含まれていません：
   - `タスク一覧表示欄（タスク編集、タスク状態変更、削除もできるように）<br>「高優先度タスク一覧表示」ボタン<br>「締切間近タスク表示」ボタン<br>「ピン止めタスク表示」ボタン<br>「完了タスク表示/非表示」切り替えトグル<br>タスク作成ボタン`
3. ホーム画面において20件を超えるタスクが存在した場合のページ遷移操作UIが未定義となっており、一覧画面とのUI一貫性および実装漏れのリスクがあります。

## 3. 推奨される修正案
`screen_design.md` の「ホーム画面」（Line 18）の構成要素欄に「ページネーション操作UI（前へ/次へボタン、ページ番号）」を追加してください：

```markdown
- 修正前: ...「完了タスク表示/非表示」切り替えトグル<br>タスク作成ボタン
+ 修正後: ...「完了タスク表示/非表示」切り替えトグル<br>ページネーション操作UI（前へ/次へボタン、ページ番号）<br>タスク作成ボタン
```
