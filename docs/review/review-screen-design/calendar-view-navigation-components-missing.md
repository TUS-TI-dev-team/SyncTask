# タスク一覧画面のカレンダー表示形式における年月ナビゲーション等のUI構成要素の記載不足

- **Status**: open
- **Severity**: Minor
- **Created At**: 2026-08-16 00:22:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）ではタスク一覧においてカレンダー表示（日付セル上にタスクを配置）が要求されていますが、`screen_design.md` の「タスク一覧画面」および補足説明において、カレンダー表示時の表示年月移動・切り替え（前月/翌月/今月移動ボタン等）やカレンダーグリッド表示部のUI構成要素が明記されていません。

## 2. 詳細な指摘内容
1. `requirements.md`（Line 121-125）では「カレンダー表示: 締切日時が設定されている全ステータスのタスクについて、日本標準時（JST）における日付（YYYY-MM-DD）のセル上に配置して表示する」と規定されています。
2. `screen_design.md` の「タスク一覧画面」（Line 24）の構成要素には「`タスク一覧表示欄<br>...<br>「表示形式切り替え」ボタン`」のみが記載されており、カレンダー表示時に必須となる「年月表示・年月切り替えナビゲーション（前月・次月・今日ボタン等）」および「カレンダーグリッド表示部」についての言及が不足しています。

## 3. 推奨される修正案
「タスク一覧画面」の構成要素欄または「タスク操作補足」に、カレンダー表示形式選択時のUI構成要素（年月表示および前月/次月/今月切り替えボタン、カレンダーセル表示領域等）を補足・明記してください。
