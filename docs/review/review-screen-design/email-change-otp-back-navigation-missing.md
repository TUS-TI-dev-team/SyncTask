# アカウント関連/OTP入力画面における「戻る」ボタンの遷移先記載漏れ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-14 20:53:30
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
`screen_design.md` の「アカウント関連/OTP入力画面」（メールアドレス変更用OTP画面）の構成要素には「`「戻る」ボタン`」が存在しますが、画面一覧テーブルの「遷移先」カラムには `ログイン画面`（完了時）しか記述されておらず、「戻る」ボタンを押した際の中断・キャンセル遷移先が欠落しています。

## 2. 詳細な指摘内容
1. `プロフィール編集画面`（Line 39）でメールアドレス変更を行った際、「アカウント関連/OTP入力画面」へ遷移します。
2. 「アカウント関連/OTP入力画面」（Line 40）の構成要素には「`「戻る」ボタン`」が含まれていますが、遷移先カラムには `ログイン画面` のみが記載されています。
3. ユーザーがメールアドレス変更を中断して「戻る」ボタンを押した場合に、`プロフィール編集画面`（または `プロフィール表示画面`）へ戻る動きが遷移先カラムに明記されていません。

## 3. 推奨される修正案
`アカウント関連/OTP入力画面`（Line 40）の「遷移先」カラムを以下のように修正してください：

```markdown
| アカウント関連/OTP入力画面 | 新メールアドレス宛に送信されたOTPを入力する... | 決定（認証成功）：ログイン画面<br>戻る・キャンセル：プロフィール編集画面 | OTP入力欄... |
```

## 修正完了報告

- **Resolved At**: 2026-08-14 20:58:00
- **Status**: Resolved

### 実施した修正内容
ユーザー確認方針（`プロフィール編集画面` へ戻る）に基づき、`screen_design.md` の「アカウント関連/OTP入力画面」の遷移先カラムを「決定（認証成功）：ログイン画面<br>戻る・キャンセル：プロフィール編集画面」に修正しました。
