# パスワード再設定画面における仮セッション有効期限の要件不一致（5分 vs 15分）

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-14 20:45:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）ではパスワードリセット用OTP検証成功後の仮セッション有効期限が「15分間」と規定されていますが、`screen_design.md` の「パスワードリセット/パスワード再設定画面」では「5分以内に操作が完了していない場合は...」と記載されており、仕様不一致が発生しています。

## 2. 詳細な指摘内容
1. `requirements.md`（機能要件 パスワードリセット Line 75, セキュリティ セッション管理 Line 233）では以下のように規定されています：
   - 「OTP検証成功時に当該OTPセッションのステータスを『検証済み』に変更し、そこから仮セッションの有効期限を15分間とする」
2. `screen_design.md` の「パスワードリセット/パスワード再設定画面」(Line 12) では：
   - 「5分以内に操作が完了していない場合はセッション切れとしてパスワードリセット/メールアドレス入力画面へ戻るよう表示する」と記載されており、有効期限が5分となっています。
   - OTP自体の入力制限時間は5分ですが、OTP認証完了後のパスワード再設定画面での仮セッション期限は15分間であるため表記が一致していません。

## 3. 推奨される修正案
1. 「パスワードリセット/パスワード再設定画面」(Line 12) の役割・機能欄の制限時間を「15分以内に操作が完了していない場合は...」へ修正してください。
