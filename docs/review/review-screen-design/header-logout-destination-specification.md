# ヘッダーにおけるログアウト実行後の遷移先（ログイン画面）の明示漏れ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 00:22:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）およびAPI設計書（`docs/design/api_design.md`）ではログアウト実行時にセッションCookieを無効化してログイン画面へリダイレクトする仕様となっていますが、`screen_design.md` の「ヘッダー」部品の「遷移先」カラムでは「`ログアウト`」とアクション名がそのまま書かれており、ログアウト完了後の遷移先画面（ログイン画面）が明確に記載されていません。

## 2. 詳細な指摘内容
1. `requirements.md`（Line 67）では「クライアント側のセッションCookieを即座に無効化（消去）し、ログイン画面にリダイレクトする」と規定されています。
2. `api_design.md`（Line 17）でも「Cookie (session_id) 削除後にログイン画面へリダイレクト」と定義されています。
3. `screen_design.md` のヘッダー部品（Line 48）の「遷移先」欄には「`ホーム<br>タスク一覧画面<br>プロフィール表示画面<br>ログアウト`」と記載されており、ログアウト後の到達先が画面名として定義されていません。

## 3. 推奨される修正案
「ヘッダー」の遷移先欄を「`ホーム画面<br>タスク一覧画面<br>プロフィール表示画面<br>ログアウト実行時：ログイン画面`」のように、ログアウト処理後の画面遷移先が「ログイン画面」であることを明示してください。

### 実施した修正内容
ユーザー確認方針に基づき、`screen_design.md` のヘッダー部品の遷移先カラムを「ホーム<br>タスク一覧画面<br>プロフィール表示画面<br>ログアウト（ログイン画面へ遷移）」と明記し、役割・機能欄に「ログアウト時はセッション破棄の上でログイン画面へリダイレクト」を追記しました。
