# 「締切間近タスク表示」選択時における完了タスク非表示トグルの表示・制御補足の欠落

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-14 20:53:30
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`requirements.md` L98）では「締切間近タスク表示」の対象ステータスは「『未着手』『進行中』のタスクのみ（『完了』タスクは除外）」と厳格に定められていますが、ホーム画面で「締切間近タスク表示」を選択した際、画面上の「完了タスク表示/非表示切り替えトグル」がどのように制御されるかの補足説明が欠落しています。

## 2. 詳細な指摘内容
1. `requirements.md`（L98）には、「締切間近タスク表示: 対象ステータス 『未着手』『進行中』のタスクのみ（『完了』タスクは除外）」と明記されており、高優先度タスクやピン止めタスクと異なり完了タスクを表示するフィルタオプションは適用されません。
2. しかし `screen_design.md` の「ホーム画面」（Line 18）の構成要素には「`「完了タスク表示/非表示」切り替えトグル`」が含まれており、補足（Line 32）においても高優先度・ピン止め・カレンダー表示での切り替えについて言及されているのみで、締切間近表示時の挙動が未規定です。
3. ユーザーが「締切間近タスク表示」を選択中にトグルを操作できてしまうと誤解を生む恐れがあります。

## 3. 推奨される修正案
「タスク操作補足」（Line 32 付近）または「ホーム画面」の仕様説明に以下の記述を追加してください：

```markdown
- 「締切間近タスク表示」ビュー選択時は、要件上「完了」タスクは常に除外されるため、「完了タスク表示/非表示」切り替えトグルは非活性（Disabled）または非表示制御とする。
```
