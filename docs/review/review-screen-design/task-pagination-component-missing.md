# タスク一覧画面におけるページネーション操作UI構成要素の記載漏れ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 00:22:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）では、タスク一覧表示において「ページネーション: 1ページあたり20件表示」と明確に規定されていますが、`screen_design.md` の「タスク一覧画面」の構成要素にページネーションを操作するためのUI要素（前へ/次へボタン、ページ番号コントロール等）が記載されていません。

## 2. 詳細な指摘内容
1. `requirements.md`（Line 108）には以下のように規定されています：
   - 「一覧表示: ページネーション: 1ページあたり20件表示」
2. `screen_design.md` の「タスク一覧画面」（Line 24）の構成要素は以下の通りです：
   - `タスク一覧表示欄<br>検索用入力欄（キーワード）<br>優先度絞り込みプルダウン<br>締切日絞り込み入力欄<br>ステータス絞り込みプルダウン<br>「完了タスク表示/非表示」切り替えトグル<br>「タスク作成」ボタン<br>「表示形式切り替え」ボタン`
3. 20件を超えるタスクが存在する場合に別ページへ遷移するためのUIパーツ（ページネーション操作部）の定義が漏れており、実装時の考慮漏れにつながる恐れがあります。

## 3. 推奨される修正案
「タスク一覧画面」（Line 24）の構成要素欄に「ページネーション操作UI（前へ/次へボタン、ページ番号表示等）」を追加してください：

```markdown
- 修正前: ...「完了タスク表示/非表示」切り替えトグル<br>「タスク作成」ボタン<br>「表示形式切り替え」ボタン
+ 修正後: ...「完了タスク表示/非表示」切り替えトグル<br>ページネーション操作UI（前へ/次へボタン、ページ番号表示等）<br>「タスク作成」ボタン<br>「表示形式切り替え」ボタン
```
