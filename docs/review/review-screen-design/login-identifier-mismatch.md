# ログイン画面およびパスワードリセット画面におけるログイン識別子（ユーザー名 vs メールアドレス）の不一致

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-14 20:28:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）では、ログインおよびパスワードリセット時に識別子として「メールアドレス」を使用する仕様となっていますが、`screen_design.md` の「ログイン画面」の構成要素および「パスワードリセット/ユーザー名入力画面」の定義において「ユーザー名」を入力する仕様になっており、要件定義との不一致が発生しています。

## 2. 詳細な指摘内容
1. **ログイン画面 (Line 7)**:
   - `screen_design.md` の構成要素に「ユーザ名入力欄」と記載されています。
   - `requirements.md`（機能要件 ログイン関係 Line 63）では「メールアドレス（ユーザー名ではない）とパスワードでログイン」と明確に規定されています。
2. **パスワードリセット画面 (Line 10)**:
   - `screen_design.md` では画面名が「パスワードリセット/ユーザー名入力画面」、役割・機能が「パスワードをリセットするユーザーの名前を入力＆認証メール送信を指示」、構成要素が「ユーザー名入力欄」となっています。
   - `requirements.md`（機能要件 パスワードリセット Line 70, セキュリティ パスワードリセット Line 174）では、「パスワードリセットのメールアドレス入力にて登録されていない...メールアドレスが入力された場合は...」と規定されており、メールアドレスを入力してリセット用OTPを発行する仕様です。

## 3. 推奨される修正案
1. **ログイン画面**:
   - 構成要素の「ユーザ名入力欄」を「メールアドレス入力欄」に修正してください。
2. **パスワードリセット画面**:
   - 画面名を「パスワードリセット/メールアドレス入力画面」に変更してください。
   - 役割・機能および構成要素の「ユーザー名」を「メールアドレス」に変更し、「メールアドレス入力欄」に修正してください。

要件定義書（requirements.md）に合わせて `screen_design.md` のログイン画面構成要素を「メールアドレス入力欄」に修正しました。また、パスワードリセット画面を「パスワードリセット/メールアドレス入力画面」へと画面名・入力欄構成を更新しました。
