# アカウント作成OTP入力画面における認証成功時遷移（ホーム画面等）の記載漏れ

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-14 20:45:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）ではアカウント作成のOTP認証成功時、自動的にログインセッションを発行してログイン状態としタスク一覧画面（ホーム画面）へ遷移する仕様となっていますが、`screen_design.md` の「アカウント作成/OTP入力画面」では遷移先が「ログイン画面」のみとなっており、認証成功後のメイン画面への遷移が欠落しています。

## 2. 詳細な指摘内容
1. `requirements.md`（機能要件 アカウント作成 Line 33）には以下のように規定されています：
   - 「OTP認証成功時、アカウントの作成を確定すると同時に自動的にログインセッションを発行してログイン状態とし、タスク一覧画面へ遷移する」
2. `screen_design.md` の「アカウント作成/OTP入力画面」(Line 9) では：
   - 遷移先が「ログイン画面」のみと記載されています。
   - OTP認証成功時に自動ログインが行われてホーム画面（またはタスク一覧画面）へ遷移する正規フローが画面遷移設計に反映されておらず、「決定」ボタン押下成功時の遷移先が不明確になっています。

## 3. 推奨される修正案
1. 「アカウント作成/OTP入力画面」(Line 9) の遷移先に「決定（認証成功）：ホーム画面（またはタスク一覧画面）」および「戻る/キャンセル：ログイン画面」を明記してください。
2. 役割・機能欄に「OTP検証成功時、自動的にログインセッションを発行してホーム画面（タスク一覧画面）へ自動遷移する」旨を追加してください。
