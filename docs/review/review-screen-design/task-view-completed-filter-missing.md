# タスク表示における完了タスク表示切り替えフィルタの構成要素漏れ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-14 20:28:00
- **Target Files**:
  - [screen_design.md](docs/design/screen_design.md)

## 1. 問題の概要
要件定義書（`docs/req-def/requirements.md`）では高優先度タスク表示・ピン止めタスク表示・カレンダー表示等において「完了タスクを含める/除外する」表示切り替えフィルタオプションを提供することが定義されていますが、`screen_design.md` の対応画面の構成要素にその操作UI要素が明記されていません。

## 2. 詳細な指摘内容
1. `requirements.md`（機能要件 タスク管理 Line 96, 102, 125）では以下のように規定されています：
   - 優先タスク・ピン止めタスク表示：「『完了』タスクの表示・非表示を切り替えるフィルタオプションを提供」
   - カレンダー表示：「カレンダー画面上に『完了タスクを含める / 除外する』の表示切り替えフィルタを提供する」
2. `screen_design.md` の「ホーム画面」(Line 18) および「タスク一覧画面」(Line 24) の構成要素欄には、「タスク一覧表示欄」「表示形式切り替えボタン」等の記載にとどまり、完了タスクの表示/非表示を切り替えるトグルボタンまたはフィルタオプションのUI構成要素が示されていません。

## 3. 推奨される修正案
1. 「ホーム画面」および「タスク一覧画面」の構成要素に「『完了タスク表示/非表示』切り替えフィルタ（トグルスイッチ等）」を追加してください。

### 実施した修正内容
`screen_design.md` の「ホーム画面」および「タスク一覧画面」の構成要素に「『完了タスク表示/非表示』切り替えトグル」を追加し、「タスク操作補足」に優先度・ピン止め・カレンダー表示での完了タスク表示切り替えトグルスイッチ制御の補足を追記しました。
