# タスクのカレンダー表示における対象ステータスおよび表示条件の未定義

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-13 21:12:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
タスク表示機能の「カレンダー表示」（L101）において、締切日時が設定されているタスクを対象とする記述があるものの、対象となるタスクステータス（「未着手」「進行中」のみか、「完了」タスクも表示するか）および絞り込み条件が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` L101 (`カレンダー表示（締切日時が設定されているタスクをカレンダー上に表示）`) では、締切日時の有無のみが条件として挙げられています。

一方、締切間近タスク表示（L79-L81）では「対象ステータス: 未着手、進行中のタスクのみ（完了タスクは除外）」と明記されています。
カレンダー表示において、「完了」ステータスのタスクを表示するのか（例: 完了済みとして視覚的に区別して表示する、またはデフォルトは未完了のみ表示でフィルタ切り替え可能とする等）、あるいは除外するのかが未定義であるため、フロントエンドのカレンダーコンポーネントおよびバックエンド取得APIの仕様決定を阻害します。

## 3. 推奨される修正案
カレンダー表示の対象タスク仕様を明確化してください：
- デフォルトでは締切日時が設定されている「未着手」「進行中」「完了」のすべてのステータスのタスクを表示対象とし、「完了」タスクは視覚的に区別できる表示（グレーアウトや打消し線等）を行える仕様とする（あるいは「完了タスクを含める」フィルタ切り替えを可能とする）。

### 実施した修正内容
`docs/req-def/requirements.md` のタスク表示（カレンダー表示）セクションを更新し、締切日時が設定されている全ステータス（「未着手」「進行中」「完了」）のタスクをカレンダー上に表示対象とすること、完了タスクは打消し線等で視覚的に区別表示すること、およびカレンダー画面上に「完了タスクを含める / 除外する」の表示切替フィルタを提供する旨を明記しました。
