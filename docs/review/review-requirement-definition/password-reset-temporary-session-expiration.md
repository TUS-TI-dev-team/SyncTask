# パスワードリセットOTP検証成功後からパスワード再設定完了までの仮セッション・有効期限の未定義

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-13 21:12:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
パスワードリセット機能において、OTPの検証（入力）に成功した後に遷移する「パスワード再設定画面」での権限（一時的なパスワードリセットセッション / トークン）の有効期限および使い捨て（Use-Once）仕様が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` L56-L60 および L149-L152 において、OTP入力成功後のパスワード再設定画面への遷移および新パスワード設定フローが記載されていますが、以下のセキュリティ・運用仕様が落としています：

1. OTPの検証成功後、パスワード変更を実行するまでの「仮セッション/ワンタイムトークン」の有効期限（例: 検証成功から15分間など）が定義されていません。
2. OTP検証完了後に画面を放置した場合や、ブラウザの戻る・進むボタンで再アクセスした場合に、同一の検証済み状態から何度でもパスワードを変更できてしまうリスクがあります。

## 3. 推奨される修正案
パスワードリセットにおけるOTP検証後のセキュリティ仕様を追加してください：
- OTP検証成功時に一時的なパスワードリセットセッション（有効期限 15分）を発行する。
- 新パスワード変更完了と同時に、当該パスワードリセットセッションおよび使用したOTPを直ちに失効・一括削除し、再利用（リプレイ攻撃）を防止する。

### 実施した修正内容
`docs/req-def/requirements.md` のパスワードリセットおよびOTPセッション管理要件を更新し、OTP検証成功時にOTPセッションのステータスを「検証済み」に変更し、そこから有効期限を15分間と設定する旨、および新パスワード設定完了時に当該パスワードリセット用OTP/仮セッションを直ちに失効・物理削除（Use-Once保証）する旨を明記しました。
