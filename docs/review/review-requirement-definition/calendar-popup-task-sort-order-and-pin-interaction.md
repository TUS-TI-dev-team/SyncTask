# カレンダー日付ポップアップ内におけるタスク並び順およびピン留め操作仕様の未定義

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 23:12:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示 > カレンダー表示（L151-L152）」において、日付セルをクリックした際に開くポップアップ内のタスク一覧表示における並び順ルール、およびポップアップ上でのピン留め状態更新（ピン留めオン/オフ）の可否が明記されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L140 および L151-L152 に以下の記述があります：

```markdown
			- 同一日付セル内に複数のタスクが存在する場合の並び順は、1. ピン留めされているタスクを優先、2. 締切時刻（hh:mm:ss）が早い順（昇順）、3. 作成日時の新しい順（降順）で表示する
			...
			- それぞれの表示形式にてある日にちをクリックするとその日のタスクを詳細に表示するポップアップを表示する
				- ポップアップ内の機能: 該当日のタスク一覧表示（タイトル・締切時刻・ステータス・優先度）、タスクのステータス切り替え、クリックによるタスク詳細/編集画面への遷移、および該当日を締切日とする新規タスク作成ボタンを提供する
```

### 仕様上の不備：
1. **ポップアップ内タスク並び順の未定義**:
   - カレンダーの日付セル内についてはソート順（1. ピン留め優先、2. 締切時刻 昇順、3. 作成日時 降順）が規定されていますが、日付をクリックして表示されるポップアップ内のタスク一覧における並び順ルール（日付セル内の並び順に準拠するのか）が明示されていません。
2. **ポップアップ上でのピン留め更新可否の未記載**:
   - 機能要件として「タスクピン止め状態更新（L101）」が定義されており、カレンダーセル内でもピン留めタスクが優先表示されますが、ポップアップ内のタスク一覧上でピン留め状態のオン/オフ切り替えが可能かどうかが明記されていません。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の L152 にポップアップ内の並び順ルール（同一日付セル内のソート順に準拠）およびピン留め切り替え機能の提供を追記してください：

```markdown
				- ポップアップ内の機能: 該当日のタスク一覧表示（タイトル・締切時刻・ステータス・優先度。並び順は日付セル内ルール［1. ピン留め優先、2. 締切時刻 昇順、3. 作成日時 降順］に準拠）、タスクのステータス切り替え、ピン留め状態の切り替え、クリックによるタスク詳細/編集画面への遷移、および該当日を締切日とする新規タスク作成ボタンを提供する
```

## 修正完了報告

- **Resolved At**: 2026-08-16 23:19:30
- **Status**: Resolved

### 実施した修正内容
ヒアリングに基づき、カレンダー日付ポップアップの仕様を以下の通り更新・明確化しました：
1. **ポップアップ内タスク並び順**: 日付セル内の並び順ルール（1. ピン留め優先、2. 締切時刻 昇順、3. 作成日時 降順）に準拠することを明記。
2. **ピン留め操作スコープ**: ポップアップ内ではピン留め状態の変更操作は提供せず、タスク詳細/編集画面へ遷移して変更を行う仕様として明確化。
