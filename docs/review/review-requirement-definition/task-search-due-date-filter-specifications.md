# タスク検索条件「締切日」における日付範囲・検索方式および未設定タスクの扱いに関する仕様不完全

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-13 20:40:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
タスク一覧表示機能の「タスク検索（and検索）」要件（L86-L95）において、検索条件項目として「締切日」が挙げられていますが、DB上のデータ型である「締切日時（日時単位）」に対する日付検索の一致基準（特定日の終日範囲検索か、指定日以前/以降の範囲検索か）および締切日時未設定タスクの扱いについての仕様が不明確です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L86-L95 に以下の記述があります：

```markdown
- タスク検索（and検索）
	- タスク名
		- 含むものを検索
	- 優先度
		- 完全一致（高、中、低）
	- 締切日
	- タスクステータス
		- 完全一致（未着手、進行中、完了）
	- コメント
		- 含むものを検索
```

### 仕様上の不備：
1. **日時の完全一致・範囲検索の基準が未定義**:
   タスク作成・編集要件（L64, L69）では「締切日時（任意）」として時刻まで保持する仕様となっていますが、検索フィルターでは「締切日（日付）」となっています。ユーザーが `2026-08-15` を検索条件に指定した場合に、`2026-08-15 00:00:00 〜 2026-08-15 23:59:59` の終日一致検索なのか、あるいは「指定日までの締め切り（〜2026-08-15 23:59:59）」などの範囲検索なのかが定義されていません。
2. **タイムゾーンの扱い**:
   クライアント端末とサーバー間のタイムゾーン差（例: JST vs UTC）により、「指定日」の範囲クエリ境界値で不一致が生じる可能性があります。
3. **締切日時未設定タスクの扱い**:
   「締切日」による絞り込みが指定された際、締切日時が未設定（`NULL`）のタスクは当然除外対象となりますが、検索条件が未指定（空）の場合と指定された場合の明確なフィルタリング動作の記述が欠落しています。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「タスク検索（and検索）」セクションを以下のように修正・明確化してください：

```markdown
- タスク検索（and検索）
	- タスク名
		- 含むものを検索（部分一致）
	- 優先度
		- 完全一致（高、中、低）
	- 締切日
		- 指定された日付の終日範囲（指定日 00:00:00 〜 23:59:59 JST）に該当する締切日時を持つタスクを検索。未設定（NULL）のタスクは除外する。未指定の場合は締切日による絞り込みを行わない。
	- タスクステータス
		- 完全一致（未着手、進行中、完了）
	- コメント
		- 含むものを検索（部分一致）
```

### 実施した修正内容
ヒアリング（`/grill-me`）での協議に基づき、要件定義書（`requirements.md`）の「タスク検索（and検索）」セクションにおいて、「締切日」指定時の絞り込み挙動を「指定日当日までの締め切り（〜指定日 23:59:59 JST）に該当する締切日時を持つタスクを検索（過去の未完了タスク等を含める、未設定タスクは除外、未指定時は絞り込みを行わない）」として明記・確定しました。
