# 毎週タスク自動作成における該当曜日なし（生成予定件数0件）時のバリデーション仕様の欠落

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-16 02:22:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク作成 > 毎週タスク自動作成（L84-L93）」において、期間バリデーション（開始日 <= 終了日、最大1年間以内）および最大件数上限（最大100件まで）は定義されていますが、指定された期間内に選択された曜日が1日も含まれず、計算上の「生成予定タスク数が0件」となるケースに対するバリデーションエラー仕様が欠落しています。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L86-L89 には以下の記述があります：

```markdown
- 期間・生成件数バリデーション:
	- 開始日 <= 終了日（開始日と終了日が同一日の場合も指定曜日に合致すれば1件作成可能）
	- 開始日には過去日も指定可能
	- 指定可能な最大期間は1年間（最大52週）以内、かつ計算される生成タスク数は最大100件まで（期間および選択曜日の組み合わせにより生成予定件数が100件を超える場合は送信前に警告または送信時に「生成件数が上限（100件）を超えています」とエラー表示し、タスクの一括作成処理を一切実行せず中断する［All-or-Nothing］）
```

### 仕様上の不備：
1. **生成予定件数0件（空振りリクエスト）の扱いが未定義**:
   - 例えば、ユーザーが「2026/08/17（月）〜 2026/08/17（月）」の1日間を指定し、選択曜日として「火曜日」のみを選択した場合、「開始日 <= 終了日」の条件は満たしますが、期間内に該当する曜日の日付が存在しないため、生成されるタスク数は0件となります。
   - この場合に、フロントエンド/バックエンドで「指定期間内に該当する曜日が存在しません」とバリデーションエラーを表示して処理を中断するのか、それとも0件作成完了（空振り成功）として正常終了メッセージを表示するのかが明記されていません。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「期間・生成件数バリデーション」に、生成予定タスク数が1件以上であること（0件の場合はエラー中断すること）を明記してください。

### 実施した修正内容
`docs/req-def/requirements.md` の「機能要件 > タスク管理 > タスク作成 > 毎週タスク自動作成 > 期間・生成件数バリデーション」において、計算される生成タスク数を1件以上100件までと規定し、期間内に選択された曜日が1日も含まれず生成件数が0件となる場合は「指定された期間内に該当する曜日が存在しません」とエラー表示して処理を中断する仕様を明記しました。
