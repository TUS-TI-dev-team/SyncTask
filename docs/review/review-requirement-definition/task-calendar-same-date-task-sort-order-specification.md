# カレンダー表示における同一日付セル内タスクのソート順（並び順）仕様の未定義

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-13 21:55:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書において、タスクのカレンダー表示機能に関する要件が規定されていますが、同一の日付（YYYY-MM-DD）セル内に複数のタスクが存在する場合におけるセル内でのタスクの並び順（ソート順）が定義されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の以下の箇所に記載があります：

- **L87-L90（一覧表示のソート順）**:
  ```markdown
  - 並び順（デフォルトソート）:
  	1. ピン留めされているタスクを最上部に優先表示
  	2. 締切日時が設定されているタスクを締切日の近い順（昇順）で表示
  	3. 締切日時が未設定または同日のタスクは作成日時の新しい順（降順）で表示
  ```

- **L104-L107（カレンダー表示）**:
  ```markdown
  - カレンダー表示
  	- 締切日時が設定されている全ステータス（「未着手」「進行中」「完了」）のタスクについて、日本標準時（JST）における日付（YYYY-MM-DD）のセル上に配置して表示する
  	- 「完了」ステータスのタスクは、視覚的に区別（文字の打消し線やグレーアウト表示等）して表示する
  	- カレンダー画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタを提供する
  ```

### 仕様上の不備：
タスク一覧表示においては、ピン留め状態・締切日時・作成日時による厳密なソート基準（L87-L90）が定義されています。
一方、カレンダー表示における特定の1日（日付セル）内に複数件のタスクが該当する場合、セルの中でどのような順番でタスクを並べて表示するのか（例：ピン留め優先、締切時刻の早い順、作成日時の新しい順など）が未規定となっています。

ソート順が未定義のままだと、DBからのデータ取得順（主キーID順や不定順）で表示され、画面更新や環境ごとにセル内の並び順が変化してユーザーの混乱を招くリスクがあります。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「カレンダー表示」（L107付近）に、同一日付セル内におけるタスクのデフォルトソート規則を追加・明記してください。

```markdown
- カレンダー表示
	- 締切日時が設定されている全ステータス（「未着手」「進行中」「完了」）のタスクについて、日本標準時（JST）における日付（YYYY-MM-DD）のセル上に配置して表示する
	- 同一日付セル内に複数のタスクが存在する場合の並び順は、1. ピン留めされているタスクを優先、2. 締切時刻（hh:mm:ss）が早い順（昇順）、3. 作成日時の新しい順（降順）で表示する
```
