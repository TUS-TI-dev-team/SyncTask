# カレンダー全体表示（月表示）における前月・翌月のグリッド外延日タスク表示仕様の未定義

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 02:49:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示 > カレンダー表示（L138, L143-L145）」において、月間カレンダーグリッド（日曜日始まりの5〜6週間＝35〜42マス）内に表示される「対象月外の前月末日および翌月初日（余白日）」に締切日時が設定されているタスクの表示可否、および該当セルクリック時の動作仕様が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L138-L145 に以下の記述があります：

```markdown
- カレンダー表示
	- 締切日時が設定されている全ステータス（「未着手」「進行中」「完了」）のタスクについて、日本標準時（JST）における日付（YYYY-MM-DD）のセル上に配置して表示する
	- 同一日付セル内に複数のタスクが存在する場合の並び順は、1. ピン留めされているタスクを優先、2. 締切時刻（hh:mm:ss）が早い順（昇順）、3. 作成日時の新しい順（降順）で表示する
	- 「完了」ステータスのタスクは、視覚的に区別（文字の打消し線やグレーアウト表示等）して表示する
	- カレンダー画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタを提供する
	- 表示形式は下記の2パターンを選択できる
		- (default)全体表示: 日-土曜日（日曜日始まり）にて、対象月の初日（1日）から末日（月末）までの全日程が確実に含まれる週（月により5週間または6週間、あるいは常時6週間グリッド）を表示する
			- 上スクロールまたは「前週/前月」操作にて前の週・月、下スクロールまたは「次週/次月」操作にて次の週・月へ遷移・表示できる
			- 次月または前月の1日を含む行を最上部にスクロール・フォーカス表示することができる
```

### 仕様上の不備：
1. **外延日付セルにおけるタスク表示有無の未定義**:
   - 日曜日始まりのカレンダーグリッドでは、対象月の1日が水曜日の場合、前月の日曜〜火曜（3日間）がグリッドの先頭に表示され、月末が木曜日の場合、翌月の金曜・土曜（2日間）がグリッド末尾に表示されます。
   - この「前月末・翌月初の日付セル」に締切日を持つタスクについて、
     - A: グリッド内に表示されている以上、前月・翌月の日付セル上にも通常通りタスクを表示するのか
     - B: 当該日付セルをグレーアウト等の非活性表示とし、タスクは表示しない（または対象月内のタスクのみ描画する）のか
     が規定されていません。
2. **API取得範囲およびポップアップ動作への影響**:
   - バックエンドのタスク取得APIが「対象月の1日〜末日」のみを取得するのか、「画面グリッドに表示される前月・翌月の日付を含む範囲」を取得するのか、また前月・翌月の日付セルをクリックした際に該当日のタスクポップアップが開くのかが実装者によって解釈が分かれる原因となります。

## 3. 推奨される修正案
`docs/req-def/requirements.md` のカレンダー全体表示（月表示）の仕様に、グリッド内に含まれる前月・翌月の日付セルにおけるタスク表示および操作方針を追記・明確化してください：

```markdown
- (default)全体表示: 日-土曜日（日曜日始まり）にて、対象月の初日（1日）から末日（月末）までの全日程が確実に含まれる週（月により5週間または6週間、あるいは常時6週間グリッド）を表示する
	- 上スクロールまたは「前週/前月」操作にて前の週・月、下スクロールまたは「次週/次月」操作にて次の週・月へ遷移・表示できる
	- 次月または前月の1日を含む行を最上部にスクロール・フォーカス表示することができる
	- グリッド内に表示されている前月・翌月の日付セル（余白セル）はグレーアウト等の視覚的区別を行い、当該日付に締切を持つタスクも同様にセル上に表示しポップアップでの確認・操作を可能とする（バックエンドAPIはグリッド全体の開始日から終了日までのタスクを取得する）
```

### 実施した修正内容
ヒアリングに基づき、`docs/req-def/requirements.md` の「カレンダー表示 > 全体表示」に「グリッド内に表示されている前月・翌月の日付セル（余白セル）はグレーアウト等の視覚的区別を行い、当該日付に締切を持つタスクも同様にセル上に配置してポップアップでの確認・操作を可能とする（バックエンドAPIはグリッド全体の開始日から終了日までのタスクを取得する）」と明記・追加しました。
