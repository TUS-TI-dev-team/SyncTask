# 優先タスク表示におけるソート順序定義の記述矛盾およびピン留め優先ルールの欠落

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 02:49:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示 > 優先タスク表示（L106）」において、並び順が「一覧表示の並び順ルールに準拠」と明記されているにもかかわらず、直後の括弧内のルール記述から「1. ピン留めされているタスクを最上部に優先表示」が抜け落ちており、「一覧表示」の並び順ルール（L120-L123）との間で記述の矛盾・曖昧さが生じています。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L103-L107（優先タスク表示）および L120-L124（一覧表示）に以下の記述があります：

- **L103-L107（優先タスク表示）**:
  ```markdown
  - 優先タスク表示
  	- 優先度「高」のタスクを表示
  	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
  	- 並び順: 一覧表示の並び順ルール（1. 締切日時の近い順［昇順］ 2. 締切日時未設定または同日のタスクは作成日時の新しい順［降順］）に準拠
  	- ページネーション: 1ページあたり20件表示
  ```

- **L120-L124（一覧表示）**:
  ```markdown
  - 並び順（デフォルトソート）:
  	1. ピン留めされているタスクを最上部に優先表示
  	2. 締切日時が設定されているタスクを締切日の近い順（昇順）で表示
  	3. 締切日時が未設定または同日のタスクは作成日時の新しい順（降順）で表示
  - ページネーション: 1ページあたり20件表示
  ```

### 仕様上の不備：
1. **ピン留め優先ルールの記述抜け・矛盾**:
   - 優先タスク表示では「一覧表示の並び順ルールに準拠」と宣言している一方で、括弧内の例示では `1. 締切日時の近い順［昇順］ 2. 締切日時未設定または同日のタスクは作成日時の新しい順［降順］` となっており、一覧表示の最優先ルールである「ピン留めタスク優先」が含まれていません。
2. **実装時の解釈の不一致**:
   - 開発者が「一覧表示に準拠してピン留めタスクを最上位にする」と判断するか、「括弧内の記載に従ってピン留めは無視し締切日時順にする」と判断するかで挙動が分かれるリスクがあります。

## 3. 推奨される修正案
優先タスク表示において、ピン留めタスクを最上位に優先表示するのか、あるいはピン留めを考慮しないのかを明確にし、記述を統一してください：

### 案A: 一覧表示に完全準拠し、ピン留めタスクを最優先する場合
```markdown
- 優先タスク表示
	- 優先度「高」のタスクを表示
	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
	- 並び順: 一覧表示の並び順ルール（1. ピン留めされているタスクを最上部に優先表示 2. 締切日時が設定されているタスクを締切日の近い順［昇順］ 3. 締切日時が未設定または同日のタスクは作成日時の新しい順［降順］）に準拠
	- ページネーション: 1ページあたり20件表示
```

### 案B: 優先タスク表示ではピン留めによる並び替えを行わない場合（採用）
```markdown
- 優先タスク表示
	- 優先度「高」のタスクを表示
	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
	- 並び順: 締切日時が早い順（昇順）。締切日時が同一または未設定の場合は作成日時の新しい順（降順）で表示（ピン留めによる並び替えは行わない）
	- ページネーション: 1ページあたり20件表示
```

### 実施した修正内容
ヒアリングに基づき、優先タスク表示では締切間近タスク表示と同様にピン留めによる並び替えは行わず、`並び順: 締切日時が早い順（昇順）。締切日時が同一または未設定の場合は作成日時の新しい順（降順）で表示（ピン留めによる並び替えは行わない）` とする方針を適用し、`docs/req-def/requirements.md` を更新しました。
