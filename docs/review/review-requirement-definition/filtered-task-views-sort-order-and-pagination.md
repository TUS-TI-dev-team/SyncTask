# 優先タスク・締切間近タスク・ピン止めタスク表示におけるソート順序およびページネーション仕様の欠落

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 02:40:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示（L103-L111）」において、「一覧表示（L112-L118）」にはソート順（1.ピン留め 2.締切日昇順 3.作成日時降順）およびページネーション（20件/頁）が明記されていますが、「優先タスク表示」「締切間近タスク表示」「ピン止めタスク表示」の各ビューにおけるタスク並び順（同一条件時のタイブレーク規則）および大量タスク存在時のページネーション/表示上限が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L103-L118 に以下の記述があります：

```markdown
- 優先タスク表示
	- 優先度「高」のタスクを表示
	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
- 締切間近タスク表示
	- 対象ステータス: 「未着手」「進行中」のタスクのみ（「完了」タスクは除外）
	- 対象時間範囲: 締切日時が現在時刻から72時間以内、または締切日時を過ぎた未完了タスク（締切日時 <= 現在時刻 + 72時間）
- ピン止めタスク表示
	- ピン留め設定がオン（`is_pinned = true`）のタスクを表示
	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
- 一覧表示
	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタオプションを提供）
	- 並び順（デフォルトソート）:
		1. ピン留めされているタスクを最上部に優先表示
		2. 締切日時が設定されているタスクを締切日の近い順（昇順）で表示
		3. 締切日時が未設定または同日のタスクは作成日時の新しい順（降順）で表示
	- ページネーション: 1ページあたり20件表示
```

### 仕様上の不備：
1. **各絞り込みビューにおける並び順の曖昧さ**:
   - 優先タスク表示（優先度「高」）において、複数のタスクが存在する場合にピン留めタスクが優先されるのか、締切日時順なのか、作成日時順なのかが規定されていません。
   - 締切間近タスク表示において、締切日時の早い順（昇順）で並べるのか、ピン留めが最上位に来るのかが明確ではありません。
   - ピン止めタスク表示において、締切日時の早い順なのか作成日時の新しい順なのかが定義されていません。
2. **ページネーションおよび表示件数制限の欠落**:
   - 優先タスクやピン止めタスクが多数存在する場合に、一覧表示と同様に1ページ20件でページネーションを行うのか、あるいは最大表示件数を設けるのかが未規定です。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「優先タスク表示」「締切間近タスク表示」「ピン止めタスク表示」に、各ビューでの並び順およびページネーション要件を追加・明確化してください：

```markdown
- 優先タスク表示
	- 優先度「高」のタスクを表示
	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
	- 並び順: 一覧表示の並び順ルール（1.ピン留め優先 2.締切日時昇順 3.作成日時降順）に準拠
	- ページネーション: 1ページあたり20件表示
- 締切間近タスク表示
	- 対象ステータス: 「未着手」「進行中」のタスクのみ（「完了」タスクは除外）
	- 対象時間範囲: 締切日時が現在時刻から72時間以内、または締切日時を過ぎた未完了タスク（締切日時 <= 現在時刻 + 72時間）
	- 並び順: 締切日時が早い順（昇順）。締切日時が同一の場合は作成日時の新しい順（降順）で表示（ピン留めによる並び替えは行わない）
	- ページネーション: 1ページあたり20件表示
- ピン止めタスク表示
	- ピン留め設定がオン（`is_pinned = true`）のタスクを表示
	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
	- 並び順: 1.締切日時が設定されているタスクを締切日の近い順（昇順） 2.締切日時未設定または同日は作成日時の新しい順（降順）
	- ページネーション: 1ページあたり20件表示
```
