# タスク隔週自動作成機能における生成方式・基準週・締切日時・DoS対策バリデーションの未定義

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-16 01:42:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク作成（L84-L87）」において、新たに追加された隔週タスク自動作成機能（「期間と曜日を指定し、その範囲内で隔週にタスクを自動作成できる」）について、生成タイミング（即時一括DB登録か定期ジョブ生成か）、隔週の起算基準週、生成されるタスクの締切時刻等の属性値、およびDoS/DB枯渇防止のための期間・件数バリデーション仕様が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L84-L87 に以下の記述が追加されています：

```markdown
		- 期間と曜日を指定し、その範囲内で隔週にタスクを自動作成できる
			- 期間は開始日と終了日をそれぞれYYYY/MM/DD形式で入力できる
			- 期間の指定はテキスト入力またはポップアップ表示のカレンダーから選択できる
			- 曜日は「月、火、水、木、金、土、日」より1つまたは複数選択可能
```

### 仕様上の不備：
1. **生成方式（即時一括生成 vs 定期バックグラウンド生成）の未定義**:
   - ユーザーが作成ボタンを押下した時点で指定期間内の全該当日タスクレコードを一括でDBにINSERTする方式（即時一括生成）なのか、あるいは「繰り返し設定」を親レコードとして保持し、バックグラウンドのCron/ジョブワーカーが到来日ごとに生成する方式なのかが規定されていません。
2. **隔週の起算基準週の曖昧さ**:
   - 「隔週（2週間に1回）」の基準が「開始日が含まれる週」を第1週（作成週）とし、翌週をスキップ（作成なし）、翌々週を作成週とするのか等、隔週判定の起算ルールが定義されていません。
   - 複数曜日（例: 月曜と水曜）が選択された場合、同一週内の月・水が作成対象となり翌週がスキップされる（週単位の隔週）のか、曜日ごとに独立して隔週判定されるのかが不明瞭です。
3. **自動生成タスクの属性および締切時刻（hh:mm:ss）の未定義**:
   - 自動生成される各タスクの「締切日時」について、日付は該当日となるものの、時刻部分（例: `23:59:59 JST` 固定なのか、フォームで締切時刻を指定可能なのか、未設定なのか）が未定義です。
   - タスク名、優先度、コメント、初期ステータス（未着手）がどのように各タスクへコピーされるかの定義が必要です。
4. **期間入力バリデーションおよびDoS対策（上限値）の欠落**:
   - 開始日と終了日の前後関係（`開始日 <= 終了日`）、開始日に過去日を指定可能かどうかのバリデーションが未定義です。
   - 指定可能な最大期間（例: 最大1年 / 最大52週）や最大生成件数（例: 最大100件等）の上限制限が定義されていないため、悪意あるユーザーまたは誤操作で100年後などを指定された場合に数千〜数万件のレコードが瞬時にDB登録され、サーバーリソースやDBを枯渇させるDoSリスクが存在します。
5. **生成後のタスクの個別・一括管理方針**:
   - 自動生成された個々のタスクは、独立した通常タスクとして個別に編集・削除されるのか、それとも「この繰り返しタスクを一括変更/削除」する仕様があるのかが不明確です。

## 3. 推奨される修正案
`docs/req-def/requirements.md` のタスク作成の記述を以下のように具体化・拡充してください：

```markdown
		- 期間と曜日を指定し、その範囲内で隔週にタスクを自動作成できる（即時一括生成方式）
			- 期間指定: 開始日と終了日をそれぞれYYYY/MM/DD形式で入力（テキスト入力またはポップアップカレンダーから選択）
			- 期間・生成上限バリデーション:
				- 開始日は作成日当日以降（過去日はエラー）
				- 開始日 <= 終了日
				- 指定可能な期間は最大1年間（365日）以内、かつ生成タスク数は最大100件まで（上限超過時はエラー表示）
			- 曜日指定: 「月、火、水、木、金、土、日」より1つ以上選択必須
			- 隔週判定基準: 開始日を含む週（日曜日始まり）を「第1週（作成対象週）」とし、以降「1週スキップ・1週作成」のサイクルで期間終了日まで該当日（指定曜日）のタスクを一括作成する
			- 生成タスクの属性: 入力されたタスク名、優先度、コメントをそのまま適用し、ステータスは「未着手」、締切日時は該当日の `23:59:59 JST`（締切時刻指定がある場合はその時刻）を設定する
			- 生成後の個別独立性: 自動作成されたタスクはそれぞれ独立した通常タスクとしてDBに個別登録され、以降は個別に編集・状態変更・削除が可能（繰り返しタスク間の一括連動更新機能は提供しない）
```

### 実施した修正内容
ヒアリングに基づき、タスク作成機能の繰り返し仕様について以下の通り `docs/req-def/requirements.md` に明記・更新しました：
1. **生成方式**: フォーム送信時に期間内の全該当日タスクレコードを一括即時生成（INSERT）する方式と定義。
2. **周期**: 隔週から「毎週」作成へ仕様を変更。
3. **期間・件数バリデーション（DoS対策）**: 開始日 <= 終了日の前後チェック、過去日指定の許可、最大期間1年（最大52週）・最大生成件数100件の上限バリデーションを追加。
4. **属性・締切時刻の適用**: フォームで入力されたタスク名・優先度・コメント・初期ステータス（未着手）を各タスクにコピーし、フォームで指定された締切時刻（hh:mm JST）を全該当日付に適用する仕様を明記。
5. **個別独立性**: 生成されたタスクはDB上で独立した通常タスクとして管理され、個別に編集・ステータス更新・削除が可能である旨を規定。
