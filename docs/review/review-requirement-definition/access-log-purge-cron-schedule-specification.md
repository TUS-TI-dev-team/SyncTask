# DBアクセスログ物理削除Cronジョブの実行時刻・スケジュールの未定義

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-13 21:02:19
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「非機能要件 > ログ管理 > ログ保持・パージ方針（L183）」において、DBアクセスログの削除処理について「日次Cronジョブにて経過レコードを物理削除する」と漠然と記載されており、具体的な実行時刻・タイムゾーンおよびCron構文が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L181-L183 に以下の記述があります：

```markdown
- ログ保持・パージ方針
	- ログイン情報・メール認証ログ: 1年間保持し、経過後に順次物理削除する
	- DBへのアクセスログ: 90日間保持し、日次Cronジョブにて経過レコードを物理削除する
```

1. **実行時刻およびCron構文の欠落**:
   「日次Cronジョブにて」としか記載されておらず、何時に実行されるのか（例: `毎日 01:00 JST / Cron: 0 1 * * *` など）が規定されていません。
2. **他セッション削除ジョブとの衝突防止**:
   ログインセッションの削除ジョブが「毎日 00:00 JST (`0 0 * * *`)」に設定されているため（L207）、DBアクセストラフィックやバックアップ処理の負荷が集中しないよう、DBアクセスログの削除Cronの具体的な実行時刻を独立して明確に定義する必要があります。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「ログ保持・パージ方針」の記述を、他のCron削除処理と同様に明確な時刻およびCron構文を含めて記述してください：

```markdown
- ログ保持・パージ方針
	- ログイン情報・メール認証ログ: 1年間保持し、経過後に順次物理削除する
	- DBへのアクセスログ: 90日間保持し、日次Cronジョブ（毎日 01:00 JST / Cron: `0 1 * * *`）にて経過レコードを物理削除する
```

### 実施した修正内容
`docs/req-def/requirements.md` の「非機能要件 > ログ管理 > ログ保持・パージ方針」において、DBアクセスログのパージCronジョブの実行時刻・タイムゾーンおよびCron構文を「毎日 01:00 JST / Cron: `0 1 * * *`」と明確に定義し、ログインセッションパージジョブ（00:00 JST）との実行時刻重なりによる負荷集中を回避する仕様としました。
