# 同名ユーザー許可に伴う監査ログ記録項目の不備（一意な識別子の欠落）

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-11 22:45:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書では同名ユーザー名の登録が許可（L159）されていますが、ログ管理要件（L146-L151）における記録対象項目が「ユーザー名」となっており、同名のユーザーが複数存在した場合にアクセスログやログインログから特定のユーザー（アカウント）を一意に特定・追跡できない不備があります。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の以下の記述に問題があります：

- **L159（ユーザー名要件）**: `同名のユーザー名登録は可（ログイン識別子にはメールアドレスを使用するため）`
- **L147-L150（ログ管理）**:
  ```markdown
  - ログ管理
  	- ログイン情報
  		- 日時，ユーザー名，IPアドレス，可否
  	- DBへのアクセスログ
  		- 日時，ユーザ名，エンドポイント，閲覧対象
  ```

ユーザー名がユニークでない（重複を許容する）設計において、ログに表示名としての「ユーザー名」のみを記録すると、障害調査やセキュリティ監査（不正アクセス・データ侵害の追跡）の際に、同姓同名・同ユーザー名のどのユーザーがアクセスしたのかをシステム上で判定できません。

## 3. 推奨される修正案
ログ記録項目にシステム内で一意な識別子（UID または メールアドレス）を含めるよう、ログ管理要件を更新してください：

```markdown
- ログ管理
  - ログイン情報
    - 日時、ユーザーID (UID)、メールアドレス、IPアドレス、ログイン成否
  - DBへのアクセスログ
    - 日時、ユーザーID (UID)、アクセス元IPアドレス、エンドポイント、閲覧・操作対象リソースID
```
