# 毎週タスク自動作成における締切時刻の入力必須性・省略時仕様および100件超過時バリデーションの未定義

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-16 02:04:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク作成（L84-L93）」において定義されている「毎週タスク自動作成機能」について、通常タスク作成（L82）では任意である「締切日時」の時刻部分（hh:mm）を自動作成フォームでどのように扱うか（省略可能か・必須か・省略時のデフォルト値）が未定義です。また、指定期間（最大1年間）と選択曜日数の組み合わせでタスク生成件数が上限（100件）を超過する場合の事前バリデーションおよびトランザクション整合性（All-or-Nothing）が規定されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L81-L93 に以下の記述があります：

- **L82（通常タスク作成）**:
  - `締切日時（任意:YYYY/MM/DD hh:mm format JST）`
- **L89-L92（毎週タスク自動作成）**:
  - `指定可能な最大期間は1年間（最大52週）以内、かつ生成タスク数は最大100件まで（上限超過時はエラー表示）`
  - `曜日指定: 「月、火、水、木、金、土、日」より1つまたは複数選択可能（1つ以上選択必須）`
  - `生成タスクの属性: 入力されたタスク名、優先度、コメント、初期ステータス（「未着手」）を各タスクへコピーし、締切日時として指定された時刻（hh:mm JST）を各生成タスクの日付に適用する`

### 仕様上の不備：
1. **締切時刻（hh:mm JST）の入力仕様・省略時挙動の欠落**:
   - 通常タスク作成（L82）では締切日時は「任意」とされていますが、自動作成（L92）では「締切日時として指定された時刻（hh:mm JST）を各生成タスクの日付に適用する」と記載されています。
   - 自動作成フォームにおいて、締切時刻の入力は「必須」なのか、それとも「任意（省略時はデフォルト値として 23:59 JST が設定される、あるいは締切時刻なし・終日扱いとなる）」なのかが定義されていません。
2. **期間（最大1年）× 選択曜日数による100件上限超過の事前バリデーション不足**:
   - 期間を1年（約52週）とし、曜日を複数選択（例: 月・水・金の3曜日 → 156件、全7曜日 → 364件）した場合、期間単体では「1年以内」を満たしていても生成タスク数が100件の上限を大幅に超過します。
   - 入力フォームのUI上で期間と曜日を選択した段階で生成予定件数をリアルタイム表示・警告するのか、また送信時に「生成予定件数が100件を超えています（○○件）」と事前検知してエラーとし、DBへのINSERTを一切実行しない（All-or-Nothing）のかが明記されていません。
3. **開始日・終了日が同一日の場合の境界値仕様**:
   - 開始日と終了日に同日（`開始日 = 終了日`）を指定し、その日の曜日が選択されている場合に「1件」のタスクが正常に生成されるかどうかの境界値仕様が明記されていません。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「タスク作成 > 毎週タスク自動作成」の記述を以下のように具体化・補足してください：

```markdown
		- 期間と曜日を指定し、その範囲内で毎週タスクを自動作成できる（即時一括生成方式）
			- 期間指定: 開始日と終了日をそれぞれYYYY/MM/DD形式で入力（テキスト入力またはポップアップ表示のカレンダーから選択可能）
			- 期間・生成件数バリデーション:
				- 開始日 <= 終了日（開始日と終了日が同一日の場合も指定曜日に合致すれば1件作成可能）
				- 開始日には過去日も指定可能
				- 指定可能な最大期間は1年間（最大52週）以内、かつ計算される生成タスク数は最大100件まで（期間および選択曜日の組み合わせにより生成予定件数が100件を超える場合はフォーム送信前に警告または送信時に「生成件数が上限（100件）を超えています」とエラー表示し、タスクの一括作成処理を一切実行せず中断する［All-or-Nothing］）
			- 曜日指定: 「月、火、水、木、金、土、日」より1つまたは複数選択可能（1つ以上選択必須）
			- 毎週作成サイクル: 開始日から終了日までの期間内で、選択された該当曜日ごとに毎週タスクを生成する
			- 生成タスクの属性: 入力されたタスク名、優先度、コメント、初期ステータス（「未着手」）を各タスクへコピーする。締切時刻（hh:mm JST）は任意入力とし、指定がある場合はその時刻を各該当日付に適用し、未指定の場合は該当日の「23:59 JST」をデフォルト締切時刻として適用する
			- 生成後の個別独立性: 自動作成されたタスクはそれぞれ独立した通常タスクとしてDBに個別登録され、以降は個別に編集・状態変更・削除が可能（繰り返しタスク間の一括連動更新機能は提供しない）
```

### 実施した修正内容
`docs/req-def/requirements.md` のタスク作成要件において、以下の仕様を明確化・追記しました：
1. 単体タスク作成および毎週タスク自動作成において、締切日時の時刻部分（hh:mm JST）を任意入力とし、未指定（省略）時はデフォルト締切時刻として「23:59 JST」を補完・適用する仕様を定義しました。
2. 毎週タスク自動作成において、開始日と終了日が同一日の場合（開始日 = 終了日）も指定曜日に合致すれば1件作成可能である旨の境界値を明記しました。
3. 期間および選択曜日の組み合わせにより計算される生成タスク数が100件を超える場合は送信前警告または送信時にエラーとし、タスクの一括作成処理を一切実行せず中断するトランザクション整合性（All-or-Nothing）を明記しました。
