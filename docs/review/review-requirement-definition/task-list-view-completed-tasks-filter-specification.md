# タスク一覧表示における完了タスクのデフォルト表示状態および表示切替フィルタ仕様の欠落

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-16 02:04:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「タスク表示（L103-L145）」において、「優先タスク表示（L106）」「ピン止めタスク表示（L112）」「カレンダー表示（L135）」では「完了」タスクのデフォルト表示状態（未完了のみ表示）および完了タスクの表示・非表示を切り替えるフィルタオプションが定義されていますが、アプリケーションのメインビューである「一覧表示（L113-L118）」には完了タスクをデフォルトで表示するのか除外するのか、また表示切替フィルタを提供するのかが明記されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L104-L135 において、各ビューの対象ステータスが以下のように定義されています：

- **優先タスク表示（L106）**: `対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）`
- **締切間近タスク表示（L108）**: `対象ステータス: 「未着手」「進行中」のタスクのみ（「完了」タスクは除外）`
- **ピン止めタスク表示（L112）**: `対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）`
- **カレンダー表示（L135）**: `カレンダー画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタを提供する`
- **一覧表示（L113-L118）**:
  ```markdown
  - 一覧表示
    - 並び順（デフォルトソート）:
      1. ピン留めされているタスクを最上部に優先表示
      2. 締切日時が設定されているタスクを締切日の近い順（昇順）で表示
      3. 締切日時が未設定または同日のタスクは作成日時の新しい順（降順）で表示
    - ページネーション: 1ページあたり20件表示
  ```

### 仕様上の不備：
1. **他ビューとの設計不整合と画面の視認性悪化**:
   - 一覧表示（L113）に対象ステータスの規定がないため、完了タスクがデフォルトで混在して表示されるのか、除外されるのかが不明です。
   - もし完了タスクが全件混在する場合、タスク完了後も一覧に残り続け、未完了タスクが埋もれてしまいます。またピン留めされた完了タスクや過去の締切を持つ完了タスクが一覧の上位に居座るなど、一覧画面の利便性が著しく低下します。
2. **完了タスク表示切り替えUIの欠落**:
   - 優先タスクやピン留めタスクと同様に、通常の一覧表示画面においても「完了タスクを含める / 除外する（または完了タスクの表示・非表示）」を切り替えるフィルタUIを提供するのかどうかの定義が必要です。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「タスク表示 > 一覧表示」の要件に、対象ステータスのデフォルト方針と完了タスク表示切替フィルタの提供を明記してください：

```markdown
		- 一覧表示
			- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタオプションを提供）
			- 並び順（デフォルトソート）:
				1. ピン留めされているタスクを最上部に優先表示
				2. 締切日時が設定されているタスクを締切日の近い順（昇順）で表示
				3. 締切日時が未設定または同日のタスクは作成日時の新しい順（降順）で表示
			- ページネーション: 1ページあたり20件表示
```

### 実施した修正内容
`docs/req-def/requirements.md` の「タスク表示 > 一覧表示」において、他ビュー（優先タスク・ピン止めタスク・カレンダー）と整合させ、デフォルトは「未着手」「進行中」の未完了タスクのみを表示し、画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタオプションを提供する仕様を明記しました。
