# タスク一覧表示におけるソート順序（並び順）およびページネーション仕様の未定義

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-11 22:45:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
タスク表示およびタスク検索機能（L69-L85）において、表示されるタスクのデフォルト並び順（ソート基準）や、大量データ存在時の表示制限（ページネーション / 無限スクロール）についての仕様が定義されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の以下の記述に不足があります：

- **L69-L84（タスク表示・一覧表示）**:
  - 「優先タスク表示」「締切間近タスク表示」「ピン止めタスク表示」「一覧表示（検索）」等のビューが定義されていますが、各ビューでタスクがどのような順序で並ぶのか（例: 締切日時の昇順、作成日時の降順、ピン留め優先など）が明記されていません。
  - ユーザーが作成したタスク数が数百件〜数千件に達した場合の表示パフォーマンス対策（1ページあたり50件表示など）が考慮されていません。

## 3. 推奨される修正案
タスク一覧の表示ルールにソート順およびページネーション要件を追加してください：

```markdown
- タスク表示仕様
  - 並び順（デフォルトソート）:
    1. ピン留めされているタスクを最上部に表示
    2. 締切日時が設定されているタスクを締切日の近い順（昇順）で表示
    3. 締切日時が未設定のタスクは作成日時の新しい順（降順）で表示
  - ページネーション: 1ページあたり20件表示
```
