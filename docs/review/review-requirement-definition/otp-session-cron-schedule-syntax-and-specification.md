# OTPセッション定期削除Cronスケジュールの表記不備および定義不統一

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-13 21:02:19
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「非機能要件 > セッション管理 > OTPセッション（L204）」において、不要セッションの定期削除スケジュールが「セッションの内無効になったものをCRON, 15分ごとに削除する」と自然言語で記述されており、ログインセッション（L207）のような標準的Cron構文（`*/15 * * * *`）および削除対象・方式（物理削除）の定義が不統一かつ曖昧です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L203-L207 において、以下の記述となっています：

```markdown
- OTPセッション
  - 有効期限　5分
  - セッションの内無効になったものをCRON, 15分ごとに削除する
- ログインセッション
  - 有効期限　43200分(1ヶ月)
  - 有効期限切れ（無効化済み）のセッションは、日次Cronジョブ（毎日 00:00 JST / Cron: `0 0 * * *`）にてDBから物理削除する
```

1. **表記および構文の不統一**:
   ログインセッションでは実行時刻・タイムゾーン・Cron式（`毎日 00:00 JST / Cron: 0 0 * * *`）が明記されていますが、OTPセッションでは「CRON, 15分ごとに削除する」と漠然とした表現になっています。
2. **削除対象および処理方式の不名確さ**:
   削除対象が「有効期限切れ（5分経過）または誤入力上限到達等で無効化されたOTPセッションレコード」であること、およびデータベースからの物理削除である旨が明記されていません。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「非機能要件 > セッション管理 > OTPセッション」の記述を、ログインセッションの表記に合わせた標準的なCron仕様表記に更新してください：

```markdown
- OTPセッション
  - 有効期限　5分
  - 有効期限切れまたは無効化済みのOTPセッションレコードは、Cronジョブ（15分ごと / Cron: `*/15 * * * *` JST）にてDBから物理削除する
```

`docs/req-def/requirements.md` の「非機能要件 > セッション管理 > OTPセッション」において、パージ処理の対象およびCron構文を「有効期限切れまたは無効化済みのOTPセッションレコードは、Cronジョブ（15分ごと / Cron: `*/15 * * * *` JST）にてDBから物理削除する」と標準表記に統一・明確化しました。
