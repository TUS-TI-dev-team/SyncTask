# パスワード変更機能の記述重複および要求仕様の不一致

- **Status**: Open
- **Severity**: Medium
- **Created At**: 2026-08-11 22:15:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書内の「アカウント管理」セクション（L40-L43）と「ログイン関係」セクション（L54-L57）の双方に「パスワード変更」機能が重複して記載されており、かつ仕様記述にゆらぎが存在します。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の以下の箇所で「パスワード変更」に関する記述が重複しています。

- **L40-L43（アカウント管理内）**:
  ```markdown
  - パスワード変更
  	- ログイン後のみ可能
  	- 既存のパスワードを知っていれば変更できる
  	- 変更後パスワードを入力した後再度ログインを要求する
  ```
- **L54-L57（ログイン関係内）**:
  ```markdown
  - パスワード変更
  	- ログイン後の画面からのみ可能
  	- 既存のパスワード知ってれば変更できる
  ```

L40-L43側の定義には「変更後パスワードを入力した後再度ログインを要求する（セッション破棄・再ログイン）」というセキュリティ上重要な挙動が明記されていますが、L54-L57側にはその記述がなく、要件定義の二重管理および仕様の漏れ・誤解を招く原因となっています。

## 3. 推奨される修正案
1. 「ログイン関係」セクション（L54-L57）の「パスワード変更」記述を削除し、「アカウント管理」セクションへ一元化します。
2. アカウント管理側の記述に「現在のパスワードの検証失敗制限（L129: 5回失敗でセッション破棄）」や「変更後のログインセッション破棄」を網羅して統一・整理してください。
