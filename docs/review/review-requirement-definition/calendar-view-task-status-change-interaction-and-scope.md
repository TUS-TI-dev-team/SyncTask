# カレンダー表示におけるステータス変更の操作スコープおよび3値ステータス更新インタラクションの曖昧さ

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-16 23:12:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示 > カレンダー表示（L151-L153）」において、ポップアップ内の機能として「タスクのステータス切り替え」が記載されている一方で、直後に「それぞれの形式にて各タスクのステータスを変更可能」と記述されています。この記述では、カレンダー画面（全体表示・週表示）の日付セル上で直接ステータス変更が可能なのか、それともポップアップを介した変更のみを指すのかが曖昧です。また、「未着手」「進行中」「完了」の3値ステータスに対してどのようなUI操作でステータスを更新するのかのインタラクション仕様が明確に定義されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L151-L153 に以下の記述があります：

```markdown
			- それぞれの表示形式にてある日にちをクリックするとその日のタスクを詳細に表示するポップアップを表示する
				- ポップアップ内の機能: 該当日のタスク一覧表示（タイトル・締切時刻・ステータス・優先度）、タスクのステータス切り替え、クリックによるタスク詳細/編集画面への遷移、および該当日を締切日とする新規タスク作成ボタンを提供する
			- それぞれの形式にて各タスクのステータスを変更可能
```

### 仕様上の不備：
1. **操作スコープの曖昧さ**:
   - L153の「それぞれの形式にて各タスクのステータスを変更可能」という記述が、カレンダーの「全体表示」および「週表示」の日付セル上に並ぶタスクアイテムから直接ステータス変更が可能であることを意味するのか、あるいは日付セルクリック後のポップアップ（L152）を通じて変更可能であることを指しているのかが不明確です。
   - もし日付セル上で直接ステータス変更を可能とする場合、セル自体のクリック（ポップアップ展開 L151）とステータス変更ボタン操作のイベント競合（イベント伝播防止）やセル内UIの設計が必要となります。
2. **3値ステータス更新インタラクションの未定義**:
   - タスクのステータスは「未着手」「進行中」「完了」の3状態が存在します（L98）。
   - 以前の「タスクの完了ステータス切り替え（完了チェック）」から「タスクのステータス切り替え」へ表現が変更されましたが、チェックボックスによる2値トグル（未完了/完了）なのか、ドロップダウン選択なのか、サイクリックな順次切り替えなのか、具体的な操作方法が明記されていません。

## 3. 推奨される修正案
カレンダー画面および日付ポップアップにおけるステータス変更の操作箇所（セル上での直接操作可否）と、3値ステータスの変更方法（例: ステータスドロップダウンまたはサイクリック変更ボタン）を具体化して明記してください：

```markdown
			- それぞれの表示形式にてある日にちをクリックするとその日のタスクを詳細に表示するポップアップを表示する
				- ポップアップ内の機能: 該当日のタスク一覧表示（タイトル・締切時刻・ステータス・優先度）、タスクのステータス変更（「未着手」「進行中」「完了」を選択・更新可能）、クリックによるタスク詳細/編集画面への遷移、および該当日を締切日とする新規タスク作成ボタンを提供する
			- カレンダー画面（全体表示・週表示）および日付詳細ポップアップの双方において、各タスクのステータス（未着手 / 進行中 / 完了）を直接変更可能とする（日付セル上のタスク操作時はポップアップ展開イベントを抑止する）
```

## 修正完了報告

- **Resolved At**: 2026-08-16 23:19:30
- **Status**: Resolved

### 実施した修正内容
ヒアリングに基づき、カレンダー表示におけるステータス変更仕様を以下の通り更新・明確化しました：
1. **操作スコープ**: カレンダー画面（全体表示・週表示の日付セル上）および日付詳細ポップアップの双方において、各タスクのステータス（「未着手」「進行中」「完了」）を直接変更可能と規定。
2. **イベント競合防止**: 日付セル上のタスク操作時は日付ポップアップ展開イベントを抑止（stopPropagation）する仕様を明記。
3. **3値ステータス対応**: ポップアップ内でも「未着手」「進行中」「完了」のステータス変更が可能であることを明記。
