# タスク作成・編集時におけるタスク名・コメントの空白のみ入力バリデーション未定義

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-13 21:12:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
タスク作成およびタスク編集要件（L63, L69）において、タスク名（1〜100文字）にスペースや改行等の空白文字のみ（Whitespace-Only）が入力された場合のバリデーションおよびトリム仕様が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` L63 (`タスク名（1〜100文字、必須）`) および L69 (`タスクの名前変更（1〜100文字）`) では文字数上限・下限のみ規定されています。

前後の空白除去（トリム）や空白のみ入力の拒否（例: `"   "` や `"\n\t"`）が明記されていないため、文字数チェック（1文字以上）を通過して画面上に見えない空白だけのタスクが登録・保存されてしまう可能性があります。
また、コメント（0〜1000文字）についても前後トリムの取り扱いが曖昧です。

## 3. 推奨される修正案
タスク作成・編集時のバリデーション要件として以下を追加してください：
- タスク名の入力値は前後の空白文字（半角スペース、全角スペース、タブ、改行）をトリムした上で評価し、トリム後1文字以上100文字以下であることを必須とする（空白文字のみのタスク名はエラー表示して拒否する）。
- コメントの入力値についても前後の空白文字を自動トリムして保持する。
