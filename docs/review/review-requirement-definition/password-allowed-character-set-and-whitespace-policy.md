# パスワード要件における使用可能文字セットおよびスペース・全角文字の扱い仕様の欠落

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 02:40:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「非機能要件 > セキュリティ > パスワード要件（L241-L244）」において、使用可能な文字種の全体集合（ホワイトリスト）が明示されておらず、半角スペース、全角文字（ひらがな・漢字・全角英数・全角記号）、および定義外の記号や制御文字が入力された場合のシステム挙動（許可するかバリデーションエラーとするか）が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L241-L244 に以下の記述があります：

```markdown
- パスワード要件
	- 8文字以上128文字以下
	- 英大文字、英小文字、数字、記号( `!"#$%&'()=-~^|\{}[]+;:*_/?.>,<` )の4種類のうち3種類以上を含むこと
	- ユーザ名文字列、およびメールアドレスの @ より前のローカル部（ただし4文字以上の場合に限る）を含むパスワードの設定を禁止する（いずれも大文字・小文字を区別せず［Case-Insensitive］に部分一致判定を行う）
```

### 仕様上の不備：
1. **使用可能文字セット（全体集合）の境界の曖昧さ**:
   - 上記では「4種類のうち3種類以上を含むこと」と最低限含むべき文字種が指定されていますが、これら以外の文字（半角スペース、全角文字、Unicode絵文字、制御文字等）がパスワード内に含まれていた場合の可否が明記されていません。
2. **スペースや全角文字による認証トラブルリスク**:
   - 半角スペースが許可される場合、メールアドレスやタスク名のように前後トリム処理が行われてしまうとユーザーが入力した意図と異なるパスワードが登録されてしまい、ログイン不能に陥るリスクがあります。
   - また、日本語入力システム（IME）の誤作動等で全角英数字や全角スペースが混入した場合に、システムがどのように判定するか（エラーとして弾くか否か）を明確にしておく必要があります。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「パスワード要件」に使用可能文字のホワイトリストおよびスペース・全角文字の禁止規則を明記してください：

```markdown
- パスワード要件
	- 8文字以上128文字以下
	- 使用可能文字は半角英大文字（A-Z）、半角英小文字（a-z）、半角数字（0-9）、および指定の半角記号32種( `!"#$%&'()=-~^|\{}[]+;:*_/?.>,<` )のみとし、ASCII印刷可能文字（0x21〜0x7E）に限定する（半角スペース、全角文字、制御文字等の使用はバリデーションエラーとして禁止する）
	- 英大文字、英小文字、数字、記号の4種類のうち3種類以上を含むこと
	- ユーザ名文字列、およびメールアドレスの @ より前のローカル部（ただし4文字以上の場合に限る）を含むパスワードの設定を禁止する（いずれも大文字・小文字を区別せず［Case-Insensitive］に部分一致判定を行う）
```
