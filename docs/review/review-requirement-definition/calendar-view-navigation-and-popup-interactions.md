# カレンダー表示における週表示ナビゲーション操作および日付ポップアップ操作仕様の未定義

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-16 01:42:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示 > カレンダー表示（L130-L135）」において、週表示における前週/翌週へのナビゲーション操作方法、および日付セルクリック時のポップアップ上で実行可能な操作（閲覧・完了チェック・編集・削除・新規追加等）の詳細仕様が未定義です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L130-L135 に以下の記述があります：

```markdown
			- 表示形式は下記の2パターンを選択できる
				- (default)全体表示: 日-土曜日（日曜日始まり）にて現在の月の1日を含む週から5週間を表示
					- 上のスクロールにて前の週、下スクロールにて次の週を表示
					- 次月または前月の1日を含む行を一番上に表示することができる
				- 週表示: 日-土曜日（日曜日始まり）にて現在の日を含む週を表示
			- それぞれの表示形式にてある日にちをクリックするとその日のタスクを詳細に表示するポップアップを表示する
```

### 仕様上の不備：
1. **週表示での週移動（ナビゲーション）操作の未定義**:
   - 全体表示には「上のスクロールにて前の週、下スクロールにて次の週を表示」と記載がありますが、「週表示」において前週や翌週へどのように移動するのか（例: 左右スワイプ、スクロール、「＜」「＞」ボタン、日付ピッカー等）が記載されていません。
2. **日付クリック時ポップアップの機能・インタラクションの未定義**:
   - 「ある日にちをクリックするとその日のタスクを詳細に表示するポップアップを表示する」とありますが、このポップアップ上でユーザーができること（例: タスク一覧の閲覧のみか、ステータス変更［完了チェック］、タスク詳細・編集モーダルへの遷移、その日を締切日とするタスクの新規追加等）が定義されておらず、画面設計・実装時の手戻り要因となります。

## 3. 推奨される修正案
`docs/req-def/requirements.md` のカレンダー表示仕様に、週表示のナビゲーション操作およびポップアップでの操作可能項目を明記してください：

```markdown
				- 週表示: 日-土曜日（日曜日始まり）にて指定日を含む週（7日間）を表示
					- 「前週（＜）」「翌週（＞）」ボタンまたは左右スワイプ/スクロールにより前後の週へ切り替え可能
					- 「今日」ボタンにより現在日を含む週に即座に戻るナビゲーションを提供
			- それぞれの表示形式にてある日にちをクリックするとその日のタスクを詳細に表示するポップアップ（またはサイドパネル）を表示する
				- ポップアップ内の機能: 該当日のタスク一覧表示（タイトル・締切時刻・ステータス・優先度）、タスクの完了ステータス切り替え、クリックによるタスク編集画面への遷移、および該当日を締切日とする新規タスク作成ボタンを提供する
```

## 修正完了報告

- **Resolved At**: 2026-08-16 01:59:00

### 実施した修正内容
ヒアリングに基づき、`docs/req-def/requirements.md` のカレンダー表示仕様を以下の通り具体化しました：
1. **週表示のナビゲーション**: 「前週（＜）」「翌週（＞）」ボタンや左右移動による週切り替え、および現在週へ復帰する「今日」ボタンの仕様を明記。
2. **日付ポップアップのインタラクション**: 該当日のタスク一覧表示（タイトル・締切時刻・ステータス・優先度）、完了ステータス切り替え（完了チェック）、タスククリックによる詳細/編集画面への遷移、および該当日を締切日とする新規タスク作成ボタンの提供を明記。
