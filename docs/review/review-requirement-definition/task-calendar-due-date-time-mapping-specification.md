# カレンダー表示における時刻付き締切日時の日付マス割り当て仕様の未定義

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-13 21:37:30
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
タスク管理機能において、締切は時刻情報を含む「締切日時」（Timestamp）として登録されますが、カレンダー表示（月表示・週表示等のグリッドUI）において、時刻情報を含む締切日時を「カレンダー上のどの日付マス（YYYY-MM-DD）」にマッピング・表示するかの仕様（タイムゾーン基準）が明記されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の以下の箇所に記載があります：

- **L67（タスク作成）**: `締切日時（任意）`
- **L102-L105（カレンダー表示）**:
  ```markdown
  - カレンダー表示
  	- 締切日時が設定されている全ステータス（「未着手」「進行中」「完了」）のタスクをカレンダー上に表示する
  	- 「完了」ステータスのタスクは、視覚的に区別（文字の打消し線やグレーアウト表示等）して表示する
  	- カレンダー画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタを提供する
  ```

### 仕様上の不備：
DBおよびモデル上、締切は `2026-08-15 14:30:00` のような日時型（Timestamp）で保持されます。
日単位のマス目（日付グリッド）で構成されるカレンダー画面でこれを表示する場合、タイムゾーン処理（日本標準時 JST 基準）および日付部分（YYYY-MM-DD）への割り当てルールが要件定義書に明示されていません。
特に深夜帯（例: `2026-08-15 01:00:00 JST` / UTC 換算 `2026-08-14 16:00:00`）のタスクにおいて、フロントエンドやバックエンドのタイムゾーン解釈のズレにより、カレンダー上で8月14日と8月15日のどちらのセルに配置されるかが不安定になるリスクがあります。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「カレンダー表示」セクションに、締切日時の日付セルへの割り当て基準（JSTタイムゾーン基準）を追記してください：

```markdown
- カレンダー表示
	- 締切日時が設定されている全ステータス（「未着手」「進行中」「完了」）のタスクについて、締切日時の日本標準時（JST）における日付（YYYY-MM-DD）のセル上に配置して表示する
	- 「完了」ステータスのタスクは、視覚的に区別（文字の打消し線やグレーアウト表示等）して表示する
	- カレンダー画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタを提供する
```
