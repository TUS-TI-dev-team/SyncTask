# タスク検索条件における文字列比較の英大文字・小文字区別および前後空白処理の未定義

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-13 21:02:19
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「タスク検索（L88-L98）」において、タスク名およびコメントを対象とした部分一致検索（アンド検索）における英大文字・小文字の区別（Case-Sensitivity）の有無、ならびに検索キーワード前後の空白文字（スペース）の取り扱いが定義されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L88-L98 には以下の記述があります：

```markdown
- タスク検索（and検索）
	- タスク名
		- 含むものを検索
	- コメント
		- 含むものを検索
```

1. **英大文字・小文字の区別（Case-Sensitivity）**:
   例えば「Report」というタスク名に対し、検索窓に「report」や「REPORT」と入力した際にヒットさせるか否か（英大文字・小文字を区別しない Case-Insensitive 検索を行うか）が規定されていません。
2. **前後空白のトリム処理**:
   ユーザーが検索窓に「 meeting 」のように前後に誤ってスペースを含めて入力した場合、そのまま空白込みで検索を実行するのか、前後の空白を自動除去（トリム）してから検索を実行するのかが未定義です。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「タスク検索」セクションに以下の規定を明記してください：

```markdown
- タスク検索（and検索）
  - キーワード検索（タスク名・コメント）は、入力された検索文字列の前後の空白文字を自動的に除去（トリム）し、英大文字・小文字を区別しない部分一致検索（Case-Insensitive）を行う
	- タスク名
		- 含むものを検索
	- コメント
		- 含むものを検索
```

### 実施した修正内容
`docs/req-def/requirements.md` の「機能要件 > タスク管理 > タスク表示 > 一覧表示 > タスク検索（and検索）」に、「キーワード検索（タスク名・コメント）は、入力された検索文字列の前後の空白文字を自動的に除去（トリム）し、英大文字・小文字を区別しない部分一致検索（Case-Insensitive）を行う」規定を追加し、検索動作の明確化を図りました。
