# タスク検索結果における並び順およびページネーション適用仕様の未明記

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 02:49:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示 > 一覧表示 > タスク検索（and検索）（L125-L136）」において、検索条件（キーワード、タスク名、優先度、締切日、ステータス、コメント）の詳細な一致条件は定義されていますが、検索実行後の検索結果一覧に対する「並び順（ソート規則）」および「ページネーション（1ページあたりの件数およびページリセット挙動）」の適用仕様が未明記です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L118-L136 に以下の記述があります：

```markdown
- 一覧表示
	- 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタオプションを提供）
	- 並び順（デフォルトソート）:
		1. ピン留めされているタスクを最上部に優先表示
		2. 締切日時が設定されているタスクを締切日の近い順（昇順）で表示
		3. 締切日時が未設定または同日のタスクは作成日時の新しい順（降順）で表示
	- ページネーション: 1ページあたり20件表示
	- タスク検索（and検索）
		- キーワード検索（タスク名・コメント）は、入力された検索文字列の前後の空白文字を自動的に除去（トリム）し、英大文字・小文字を区別しない部分一致検索（Case-Insensitive）を行う（未入力またはトリム後空文字の場合はキーワードによる絞り込みを行わない）
		- タスク名
			- 含むものを検索（未入力時は絞り込みを行わない）
		- 優先度
			- 完全一致（高、中、低。未指定・すべて選択時は全優先度を対象とする）
		- 締切日
			- 指定日当日までの締め切り（〜指定日 23:59:59 JST）に該当する締切日時を持つタスクを検索。未設定（NULL）のタスクは除外する。未指定の場合は締切日による絞り込みを行わない
		- タスクステータス
			- 完全一致（未着手、進行中、完了。未指定時は一覧表示の「完了タスクを含める / 除外する」フィルタ設定に従う）
		- コメント
			- 含むものを検索（未入力時は絞り込みを行わない）
```

### 仕様上の不備：
1. **検索結果におけるソート順序の未定義**:
   - 検索条件を指定して絞り込んだ結果一覧に対して、通常の一覧表示と同様のソート規則（1. ピン留め優先 2. 締切日時昇順 3. 作成日時降順）が適用されるのか、あるいは関連度順や作成日時順などの別ソートが適用されるのかが明記されていません。
2. **ページネーションおよびページ番号リセット仕様の未明記**:
   - 検索結果が20件を超える場合に通常の一覧表示と同様に1ページあたり20件でページネーションを行うのか、また検索条件を変更・再実行した際にページ番号が先頭（1ページ目）にリセットされるのかが規定されていません。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「タスク検索（and検索）」の末尾に、検索結果に対するソート規則およびページネーションの適用仕様を追記してください：

```markdown
- タスク検索（and検索）
	- キーワード検索（タスク名・コメント）は、入力された検索文字列の前後の空白文字を自動的に除去（トリム）し、英大文字・小文字を区別しない部分一致検索（Case-Insensitive）を行う（未入力またはトリム後空文字の場合はキーワードによる絞り込みを行わない）
	- タスク名
		- 含むものを検索（未入力時は絞り込みを行わない）
	- 優先度
		- 完全一致（高、中、低。未指定・すべて選択時は全優先度を対象とする）
	- 締切日
		- 指定日当日までの締め切り（〜指定日 23:59:59 JST）に該当する締切日時を持つタスクを検索。未設定（NULL）のタスクは除外する。未指定の場合は締切日による絞り込みを行わない
	- タスクステータス
		- 完全一致（未着手、進行中、完了。未指定時は一覧表示の「完了タスクを含める / 除外する」フィルタ設定に従う）
	- コメント
		- 含むものを検索（未入力時は絞り込みを行わない）
	- 検索結果の表示: 一覧表示の並び順ルール（1. ピン留め優先 2. 締切日時昇順 3. 作成日時降順）およびページネーション（1ページあたり20件表示）に準拠する。また、新たな検索を実行した際は常に1ページ目を初期表示する
```
