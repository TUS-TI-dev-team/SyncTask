# カレンダー全体表示における5週間固定表示による月末日欠落不具合

- **Status**: Resolved
- **Severity**: Major
- **Created At**: 2026-08-16 01:42:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示 > カレンダー表示（L131）」において、全体表示の表示期間を「現在の月の1日を含む週から5週間を表示」と固定定義していますが、1ヶ月は最大31日あり、月の初日（1日）が金曜日または土曜日の場合、月末日が「第6週」に配置されるため、5週間固定では月末日のタスクが表示範囲外となり欠落・閲覧不可となる不具合が発生します。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L130-L133 に以下の記述が追加されています：

```markdown
			- 表示形式は下記の2パターンを選択できる
				- (default)全体表示: 日-土曜日（日曜日始まり）にて現在の月の1日を含む週から5週間を表示
					- 上のスクロールにて前の週、下スクロールにて次の週を表示
					- 次月または前月の1日を含む行を一番上に表示することができる
```

### 仕様上の不備：
1. **月末日（第6週）の表示欠落**:
   - 日曜日始まりのカレンダーにおいて、1ヶ月が31日ある月で1日が金曜・土曜の場合（例: 2026年8月は1日が土曜日、10月は1日が木曜日、2027年5月は1日が土曜日など）、その月の全日を表示するには **6週間（42マス）** 必要となります。
   - 例（2026年8月の場合）:
     - 第1週: 7/26〜8/1（8/1のみ8月）
     - 第2週: 8/2〜8/8
     - 第3週: 8/9〜8/15
     - 第4週: 8/16〜8/22
     - 第5週: 8/23〜8/29
     - 第6週: 8/30〜9/5（8/30, 8/31は8月）
   - 「5週間（35マス）」固定で表示した場合、8月30日および31日が表示されず、月末締切のタスクがユーザーから見えなくなるという重大な表示不具合・データ欠落が生じます。

## 3. 推奨される修正案
`docs/req-def/requirements.md` のカレンダー全体表示の仕様を、月末日が確実に含まれるよう「対象月に応じて5週または6週を動的に表示する（または常時6週間の月表示グリッド）」に変更してください：

```markdown
				- (default)全体表示: 日-土曜日（日曜日始まり）にて、対象月の初日（1日）から末日（月末）までの全日程が確実に含まれる週（月により5週間または6週間、あるいは常時6週間グリッド）を表示する
					- 上スクロールまたは「前週/前月」操作にて前の週・月、下スクロールまたは「次週/次月」操作にて次の週・月へ遷移・表示できる
					- 次月または前月の1日を含む行を最上部にスクロール・フォーカス表示することができる
```

## 修正完了報告

### 実施した修正内容
ヒアリングに基づき、`docs/req-def/requirements.md` の「カレンダー表示」における全体表示の仕様を改訂しました：
- 対象月の初日（1日）から末日（月末）までの全日程が確実に含まれる週（月により5週間または6週間、あるいは常時6週間グリッド）を表示する仕様とし、月末日の表示欠落およびタスクの不可視不具合を解消しました。
