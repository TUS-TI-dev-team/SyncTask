# 締切間近タスク表示における対象タスク抽出条件および完了・超過ステータスの未定義

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-13 20:27:29
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
「締切間近タスク表示」機能において、「締め切り72時間前のタスクのみを表示する」と定義されていますが、対象となるタスクのステータス条件（完了タスクの除外有無）や締切日時が過ぎた過去タスク（期限切れタスク）の扱いについての境界仕様が明確化されていません。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の以下の記述に曖昧さがあります：

- **L76-L77（タスク表示）**:
  ```markdown
  - 締切間近タスク表示
  	- 締め切り72時間前のタスクのみを表示する
  ```

### 曖昧・未定義な点：
1. **完了済みタスクの扱い**:
   ステータスが「完了」となっているタスクについて、締切日時が72時間以内である場合に「締切間近タスク表示」に含まれるのかどうかが記載されていません。ユーザーにとって処理済みの「完了」タスクが締切間近一覧に表示され続けることはユーザー体験上不適切であり、未完了（「未着手」「進行中」）タスクのみに限定すべきです。
2. **締切日時超過（期限切れ）タスクの扱い**:
   「締め切り72時間前」という表現が、単に `現在時刻 <= 締切日時 <= 現在時刻 + 72時間` の未来の範囲を指すのか、それとも `締切日時 <= 現在時刻 + 72時間`（過去に締切を過ぎた超過タスクも含む）を指すのかが不明確です。

## 3. 推奨される修正案
「締切間近タスク表示」の抽出ロジックおよび境界条件を以下のように明確化・更新してください：

```markdown
- 締切間近タスク表示
	- 対象ステータス: 「未着手」「進行中」のタスクのみ（「完了」タスクは除外）
	- 対象時間範囲: 締切日時が現在時刻から72時間以内、または締切日時を過ぎた未完了タスク（締切日時 <= 現在時刻 + 72時間かつ未完了）
```

## 修正完了報告

- **Resolved At**: 2026-08-13 20:34:00

### 実施した修正内容
`docs/req-def/requirements.md` において、「締切間近タスク表示」の対象ステータスを「未着手」「進行中」の未完了タスクに限定し（「完了」タスクを除外）、対象時間範囲を「締切日時が現在時刻から72時間以内、または締切日時を過ぎた未完了タスク（締切日時 <= 現在時刻 + 72時間）」と規定・明確化しました。
