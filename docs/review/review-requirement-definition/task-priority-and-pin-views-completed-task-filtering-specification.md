# 優先タスク表示およびピン止めタスク表示における完了タスクの扱い・フィルタ仕様の不足

- **Status**: Resolved
- **Severity**: Medium
- **Created At**: 2026-08-13 22:15:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書（L82, L86）の「優先タスク表示（優先度：高のタスクを表示）」および「ピン止めタスク表示」において、ステータスが「完了」であるタスクを表示対象に含むか除外するかの仕様が明確に定義されていません。

## 2. 詳細な指摘内容
1. **他ビューとの整合性の欠如**:
   - 「締切間近タスク表示」（L84）では `対象ステータス: 「未着手」「進行中」のタスクのみ（「完了」タスクは除外）` と明記されています。
   - 「カレンダー表示」（L106-L109）では `全ステータス（「未着手」「進行中」「完了」）` を対象とし、`完了タスクを含める / 除外する` の表示切替フィルタを提供する仕様となっています。
   - 一方で、「優先タスク表示」（L82）および「ピン止めタスク表示」（L86）については、「完了」ステータスのタスクを含むのか除外するのかが記載されていません。
2. **実装・UI上の相反リスク**:
   - 優先度「高」やピン留めが設定されたタスクが完了状態になった際、優先タスク一覧やピン止めタスク一覧に残るのか消えるのかが曖昧なため、バックエンドAPIとフロントエンドUIで判定基準に差異（例: APIは全ステータスを返し、フロントは未完了のみ表示する等の食い違い）が生じるリスクがあります。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「優先タスク表示」および「ピン止めタスク表示」要件に、対象ステータスの明確化（デフォルトで未完了のみ表示、またはフィルタ切替等の定義）を追加してください：

```markdown
- 優先タスク表示
  - 優先度「高」のタスクを表示
  - 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
- ピン止めタスク表示
  - ピン留め設定がオン（`is_pinned = true`）のタスクを表示
  - 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（「完了」タスクの表示・非表示を切り替えるフィルタオプションを提供）
```

### 実施した修正内容
要件定義書（`docs/req-def/requirements.md`）の「優先タスク表示」および「ピン止めタスク表示」の要件項目に、デフォルト対象ステータス（「未着手」「進行中」のみ）と、完了タスクの表示・非表示を切り替えるフィルタオプションを提供する旨を明記しました。
