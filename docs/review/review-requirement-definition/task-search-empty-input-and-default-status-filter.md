# タスク検索における未指定・空文字入力時の絞り込み仕様および検索対象ステータスの曖昧さ

- **Status**: Resolved
- **Severity**: Minor
- **Created At**: 2026-08-16 02:22:00
- **Target Files**:
  - [requirements.md](docs/req-def/requirements.md)

## 1. 問題の概要
要件定義書の「機能要件 > タスク管理 > タスク表示 > 一覧表示 > タスク検索（L120-L131）」において、締切日（L127）には「未指定の場合は締切日による絞り込みを行わない」と明記されているものの、キーワード（タスク名・コメント）、優先度、タスクステータスが未入力・未選択の場合の挙動（絞り込みを行わないこと）が明記されていません。また、検索時のタスクステータス未指定において、完了タスクを含めるか否かのデフォルト動作が一覧表示のデフォルト（未完了のみ）との関係で曖昧です。

## 2. 詳細な指摘内容
`docs/req-def/requirements.md` の L114 および L120-L131 には以下の記述があります：

- **L114（一覧表示）**:
  ```markdown
  - 対象ステータス: デフォルトは「未着手」「進行中」の未完了タスクのみを表示する（画面上に「完了タスクを含める / 除外する」の表示切り替えフィルタオプションを提供）
  ```
- **L120-L131（タスク検索）**:
  ```markdown
  - タスク検索（and検索）
  	- キーワード検索（タスク名・コメント）は、入力された検索文字列の前後の空白文字を自動的に除去（トリム）し、英大文字・小文字を区別しない部分一致検索（Case-Insensitive）を行う
  	- タスク名: 含むものを検索
  	- 優先度: 完全一致（高、中、低）
  	- 締切日: 指定日当日までの締め切り（〜指定日 23:59:59 JST）に該当する締切日時を持つタスクを検索。未設定（NULL）のタスクは除外する。未指定の場合は締切日による絞り込みを行わない。
  	- タスクステータス: 完全一致（未着手、進行中、完了）
  	- コメント: 含むものを検索
  ```

### 仕様上の不備：
1. **未入力・未選択時の絞り込み除外ルールの非統一**:
   - キーワード入力欄が空文字（またはスペースのみでトリム後0文字）の場合、および優先度やタスクステータスで「すべて / 指定なし」が選択された場合に、該当条件による絞り込みをスキップ（全件対象）とする旨が締切日以外で明文化されていません。
2. **ステータス未指定時の完了タスク扱い**:
   - 検索条件としてステータスを指定しなかった場合、一覧画面の基本フィルタ設定（「完了タスクを含める / 除外する」）がそのまま適用されるのか、あるいはステータス未指定時は完了タスクも含む全件から検索されるのかが明確ではありません。

## 3. 推奨される修正案
`docs/req-def/requirements.md` の「タスク検索（and検索）」に、各検索項目の未指定時（空文字・未選択時）の共通挙動を明記してください。

## 修正完了報告

- **Resolved At**: 2026-08-16 02:32:00
- **Status**: Resolved

### 実施した修正内容
`docs/req-def/requirements.md` の「機能要件 > タスク管理 > タスク表示 > 一覧表示 > タスク検索（and検索）」において、キーワード（タスク名・コメント）未入力時および優先度未指定時の全件対象ルール、ならびにタスクステータス未指定時は一覧表示の「完了タスクを含める / 除外する」フィルタ設定に従う旨を明文化しました。
