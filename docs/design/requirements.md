## システム概要
### 背景
- チーム開発の学習のため
### 目的
- 個人向けのクロスプラットフォーム対応タスク管理Webアプリを作成し、端末間でタスク管理をできるようにすること
- チーム開発の手法について学ぶこと
### プロジェクト概要
- 個人のユーザが利用するタスク管理用Webアプリを作成する

## 業務要件（システム要件）
### このアプリを何のために使うか
- タスク管理
### 利用者の範囲
- 対象：大学生
- 規模：数人
### 期待する成果・完了条件
- 自分のタスクを作成できる
- 自分のタスクの進捗状況を把握・記録できる
- これにより、効率的なタスク管理を可能にする

## 機能要件
### ユーザー視点でできる機能
- アカウント管理
	- アカウント作成
		- ユーザー名、パスワード、メールアドレスを入力
		- メール認証を行う
			- メールにてOTPを送信
			- サイト内のOTP入力欄にOTPを入力する
			- 変更後パスワードを入力後ログインを要求
	- アカウント編集
		- ログイン後の画面からのみ可能
		- ユーザ名の変更
		- メールアドレスの変更
	- アカウントの削除
		- ログイン後の画面からのみ可能 (確認ダイアログ + パスワード再認証要)
		- アカウント本体 (`LOGIN_ACCOUNT`) は論理削除 (`IS_DELETED = TRUE`)、ログインセッションは物理削除
- ログイン関係
	- ログイン
		- ユーザ名（メールアドレスではない）とパスワードでログイン
	- ログアウト
	- パスワードリセット
		- パスワードリセットは、メール認証で行う
			- メールアドレスを持っている人間を本人とする
		- メールにてOTPを送信
		- サイト内のOTP入力欄にOTPを入力する
		- 変更後パスワードを入力後ログインを要求
	- パスワード変更
		- ログイン後の画面からのみ可能
		- 既存のパスワード知ってれば変更できる
- タスク管理
	- タスク作成
	- タスク編集（タスクの名前、コメントとか）
		- タスクの名前変更
		- タスクの優先度変更
		- 締め切り日時
		- コメントの変更
	- タスク状態更新（進行中、完了）
	- タスク削除
	- タスクピン止め状態更新
	- タスク表示
		- 優先タスク表示
		- 締切間近タスク表示
			- 72時間前
		- ピン止めタスク表示
		- 一覧表示
			- タスク検索（and検索）
				- タスク名
					- 含むものを検索
				- 優先度
				- 締切日
				- タスクステータス
					- 完全一致
				- コメント
					- 含むものを検索
		- カレンダー表示

## 非機能要件
### 性能
- 全てのページで、ターンアラウンドタイムが1秒以下
### 可用性
- 稼働率90%以上
### 対応プラットフォーム
- PC
	- OS
		- Windows
		- Linux
	- ブラウザ
		- Google Chrome
		- Microsoft Edge
		- Mozilla Firefox
- スマホ
	- OS
		- Android
	- ブラウザ
		- Google Chrome
		- Mozilla Firefox
### 運用・保守性
- サーバー異常時の管理者へのメール通知(管理者用のメーリングリストを作成)
	- プログラムエラー発生時
	- ハードウェアのメトリクス
		- CPU使用率
		- メモリ使用量
		- データベース容量
- 定期バックアップは一旦とらないことにする
### セキュリティ
- 不正アクセス対策
	- 本人以外は、そのアカウントの情報を見られない
		- 登録されているメールアドレスにアクセスできる人を本人とする
	- https通信
	- ログイン認証のセッション期限は1ヶ月とする
- ログイン認証
	- 5回連続でログインに失敗したら、30分間ロックがかかる
		- 初失敗から1時間ごとにロックをリセット
	- OTPのセッション期限 1 分
- パスワード変更時の，「現在のパスワード」認証
	- 5回連続で現在のパスワードの認証に失敗したら、セッションを破棄してログイン画面に戻す
- OTP要件
	- OTPは英数字8桁，英数字は大文字小文字を区別しない
	- 入力制限(5回)を超えて間違えた場合はOTPを新しいものにして再送する
	- 再送依頼があった際はOTPを新しいものにして再送する
- 使用ライブラリの脆弱性発見
	- 定期的に npm audit, govulncheck
- ログ管理
	- ログイン情報
		- 日時，ユーザー名，IPアドレス，可否
	- DBへのアクセスログ
		- 日時，ユーザ名，エンドポイント，閲覧対象
	- メール認証
- 脆弱性対策
	- 入力文字列のエスケープ処理
	- CSRF対策 → CSRFトークンの導入
	- 開発後に一度脆弱性診断をおこなう
- ユーザ名要件
	- 2文字以上20文字以内
	- 英小大文字、数字
- パスワード要件
	- 8文字以上128文字以下
	- 英小大文字、数字、記号( `!"#$%&'()=-~^|\{}[]+;:*_/?.>,<` )
	- ユーザ名, メールアドレスから推測不可のもの
- 検証・認証失敗時の応答速度を1s±0.1sの範囲で調整する
- メールアドレス要件
  - 他ユーザとの重複なし
  - 重複したメールアドレスが入力された場合はOTP変更画面
- セッション管理
  - トークンではなくセッションによって管理
  - OTPセッション
    - 有効期限　5分
    - セッションの内無効になったものをCRON, 15分ごとに削除する
  - ログインセッション
    - 有効期限　10080分(一週間)
    - セッションの内無効になったものをCRON, 毎日00/00に削除する
