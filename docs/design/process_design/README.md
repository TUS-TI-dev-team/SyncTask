# Process Design (処理設計)

## 概要

SyncTaskのアカウント管理・認証に関する主要ユースケースについて、フロントエンド、バックエンド、データベースおよび外部サービス間の処理順序を定義します。各文書には、対象画面・API、入力検証、認証・認可、トランザクション、セッション・Cookie、エラー応答、画面遷移およびログ記録を、必要に応じてシーケンス図とともに記載します。

本ディレクトリの文書は、次の上位文書を処理単位に具体化したものです。

- [要件定義](../../req-def/requirements/README.md)
- [API設計](../api_design/01_overview.md)
- [画面設計](../screen_design.md)
- [データベース設計](../database_design.md)

## 適用範囲

本ディレクトリが対象とするのは、現在配置されているアカウント作成、アカウント編集、アカウント削除、ログイン、ログアウト、パスワードリセットおよびパスワード変更の処理設計です。タスク管理等、目次に文書が存在しない機能の処理設計は本ディレクトリでは定義しません。

実装時は、処理設計だけでなく上位文書も参照してください。上位文書または処理設計間に不整合が見つかった場合は、推測で補完せず、関係文書の合意内容を確認して同期します。

## 設計上の共通原則

- **API・データモデル**: エンドポイント、HTTPステータス、エラーコード、Cookie属性、テーブル名およびカラム名はAPI設計・データベース設計に従います。
- **サーバーサイドセッション**: ログイン状態は `LOGIN_SESSION` とCookie `sync_task_sid` で管理し、有効な通常APIアクセスでは30日間のSliding Expirationを適用します。セッション失効処理は各ユースケースで定めた対象範囲に限定します。
- **CSRF対策**: Cookie認証を伴う状態変更APIでは、Cookie `XSRF-TOKEN` とヘッダー `X-CSRF-Token` によるDouble Submit Cookie方式で検証します。ログアウトは冪等性確保のため、有効なログインセッションが存在する場合だけ検証します。
- **入力検証と評価順序**: 構文・必須項目・形式をAPIごとの評価順序で検証し、検証前に状態変更や失敗回数加算を行いません。
- **列挙・Timing Attack対策**: アカウントやメールアドレスの存在を秘匿する対象処理では、実処理とダミー処理の応答内容・画面遷移・規定の応答遅延を揃えます。OTP期限にはDB設計の `OTP_EXPIRES_AT` と `SESSION_EXPIRES_AT` を使用します。
- **OTP画面の復元**: フロントエンドが有効期限内のOTPセッションIDと用途を保持している場合、同じ用途の入力画面を再表示せずOTP入力画面へ遷移します。`request-otp` が直接または重複操作で再度呼ばれた場合、既存の実セッションを更新・再送せず、新しいダミーセッションを作成して同一形式の応答を返します。
- **ダミーセッション**: ダミー状態も `OTP_SESSION` に保存し、`IS_DUMMY` を最終判定とします。ダミーでは実メールアドレス、パスワードハッシュ、OTPハッシュを保持せず、OTP照合を成功させません。メール変更用ダミーのみ所有者認可のため認証ユーザーIDを保持します。
- **メール送信失敗**: 実セッションのOTP送信に失敗した場合は `DELIVERY_STATUS='sendable'` として再送可能にし、同一の `otp_session_id` レコードを直接更新して再送処理を行います。送信成功時は連続失敗回数を0へ戻し、連続5回失敗時は補償処理で対象セッションを物理削除します。
- **トランザクションと削除方針**: 複数テーブルを整合的に更新する確定処理は単一トランザクションで実行し、途中失敗時はロールバックします。アカウントは論理削除、タスク・使用済みセッション等は各仕様に従って物理削除します。
- **Cookieと画面状態**: セッション破棄時は対象となるDBレコードを削除し、必要な応答で `sync_task_sid` と `XSRF-TOKEN` を失効させます。フロントエンドはAPI結果に応じて認証状態を更新し、画面設計で定めた遷移先へ移動します。
- **監査ログ**: APIアクセス、ログインおよびメール認証の各イベントは、該当するログテーブルへ記録します。パスワード、OTP、セッションID、CSRFトークン等の秘密情報はログへ出力しません。
